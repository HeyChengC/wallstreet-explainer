# 竖屏版（9:16）：29 个场景，照着填就能出片

竖屏版给手机看：1080×1920，学自小Lin说在小红书发的三条竖屏片（汽车、太空旅游、免税）。
和横屏版是两套场景：竖屏的场景名都以 `v-` 开头，横屏的场景（`host`、`person`、`ledger` 这些）不要拿到竖屏里用。

这份文档是照着填用的。**不用自己设计画面**：一句话在说什么，就去下面的表里找对应的场景，把这一句的内容填进去。位置、字号、颜色、进场都是场景自己管的。

## 精装组件 vpro（v2.6 起，新片默认用这一套）

二十个 `vp-` 开头的组件，写在 `kit/vpro.js`、`kit/vpro.css`，`new_film.mjs --vertical` 起步时已经带上。它们是《英伟达拒绝老黄回归》竖屏改到第九版、用户点头的那套画面拆出来的，样片在 `examples/nvda-vertical/`。
**样片是质量的底，不是模板**：下一条片每一镜要有自己的演法（换道具、换词、换哪一镜最重），不能照着样片换字。

**三步用上**

1. 定强调色：`python scripts/pick_accent.py <她的一帧 或 主图>`，它会报画面里最大的几堆颜色和各自能用的强调色，挑和主体最贴的那个（肤色、木头色它会标出来，不选）。在 `film.js` 的 `KIT_VERT.use(…)` 后面写一句 `KIT_VPRO.theme({accent:'#8a86ee', bg:'assets/img/主图.jpg'})`，卡的底色、细边、数字、立体字的颜色都跟着它变；`bg` 是没有她的镜头默认垫的图。
2. 每一镜先在导演表里写清"观众要懂什么、屏上有什么、怎么进来、演哪个词"，再从下表选组件。挑一两个口播里的词做成道具（见下面"道具"）。
3. `render.mjs --check` 改到没有提醒，再渲单帧拼联系表，和参考片并排看。

**两种模式，同一份镜头表**

| | 有真人口播 | 没有人出镜 |
|---|---|---|
| 声音和时间线 | 口播原片，`host_timeline.py` 逐字对齐 | 配音：每句存成 `voice/<id>.final.wav`，`temp_voice.py script.json` 对齐（设环境变量 `WHISPER_MODEL=<本机模型文件夹>`，不然会连网等很久） |
| `KIT_VERT.use` | 写 `host:{name:'host',fps:30,…}` | 不写 `host` |
| 组件垫什么 | 她的实拍；证据镜头角上有她的圆头像 | `bg`（这一镜写的，或 `theme` 里那张；没写 `bgpos` 时每镜自动换一个裁法） |
| 景别 `zoom` | 在重音的词上硬切一档 | 不用写 |
| `vp-number` 的巨数 | 有抠像时在她身后；墙暗用亮色、墙亮用深色，自己量 | 亮色，整个露出来 |
| 要多想一步的 | 相邻两个她的镜头景别差 0.15 以上 | 她不在，主角得是东西：第 1 镜把道具做大放中间，`vp-words` 用 `y` 把词挪到上面 |

两种都验证过：`examples/nvda-vertical/film.js`（有口播）和 `film_nohost.js`（无人）是同一条片；`examples/gold-rates-vertical/film_vpro.js` 是换了一个题目、换了一位口播，只用 skill 里的东西做的。

**组件表**（参数的完整说明在 `vpro.js` 每个组件的 `help` 里，写错参数名 `--check` 会报错）

| 组件 | 这一镜在说什么 | 必填 | 常用 |
|---|---|---|---|
| `vp-words` | 一两个要记住的词，卡着她说的字出现 | `words` | `en` 英文小字、`zoom` 在重音上切景别、`fx:'flip'` 整行翻一下 |
| `vp-newspile` | 这事到处在报：新闻卡飞下去摞成一摞 | `items` | `bg` 垫底的图、`brow`、`stamp` 最后盖一块牌 |
| `vp-person` | 当事人自己说了什么：抠像站前面，原话打字，巨字从身后滑出 | `cut`、`lines` | `quote`、`name`、`cardOut`、`source` |
| `vp-reject` | 转折、被拒：一个词砸下，下一个词从头顶掉下来 | `stamp` | `drop`、配一个 `pour` 道具 |
| `vp-paper` | 原文为证：带报头的纸转正，推到那一行刷黄 | `img` | `mast`、`hl`、`tag` 谁说的 |
| `vp-verdict` | 全片的结论，最重的一镜，只用一次 | `lines` | `cut` 当事人、`note` 原话卡、`hero:true` |
| `vp-voices` | 几个人表态，然后被一句话压下去 | `items` | `deny`、`bar` |
| `vp-number` | 用一个数收尾 | `value` | `unit`、`label`、`pct`；有口播抠像时数字真的在她身后 |
| `vp-ask` | 把问题抛给观众：巨大的问号压在后面 | `lines` | `at`、`zoom` |
| `vp-bars` | 几个数比大小：柱子往上长 | `items` | `unit`、`title`；`hl:true` 的那根是强调色 |
| `vp-versus` | 两样东西对着看 | `left`、`right` | `win` 让一边赢 |
| `vp-chain` | 因果链：一环扣一环 | `items` | 每环 `value`、`sub`、`img` |
| `vp-list` | 几条要点一条条翻出来 | `items` | `mark:'ok'/'no'`、`hl` |
| `vp-line` | 走势线从左画到右 | `data` | `marks`、`drawTo`、`down`、`source`（要写） |
| `vp-photo` | 一张图当主角：大窗转进来 | `img` | `tags`、`source` |
| `vp-quote` | 一句引语（没有抠像时用） | `lines`、`name` | `tag`、`img` 头像 |
| `vp-timeline` | 几个有日期的节点 | `items` | 每个 `date`、`text`、`hl` |
| `vp-share` | 一个占比：圆环画到那个百分比 | `value` | `label`、`note` |
| `vp-rank` | 有名次的比较：横条排行 | `items` | `hl` |
| `vp-chapter` | 分段的小标题（长片用） | `title` | `no`、`en` |

前 8 个加 `vp-ask` 是"讲故事"的：有口播时她是底。其余 11 个是"图形镜头"：有口播时她在右上角的圆头像里。图形镜头的内容放在一张有透视的斜台面上，卡有厚度、柱子是长方体、强调的那一项浮起来一层（某一镜想平着放写 `flat:true`）。样张：`examples/vpro-gallery/`。

**道具**：任何组件都能写 `props:[{kind, img, at, …}]`，一镜最多一样，演口播里的一个词。

| kind | 演什么 | 图要什么样 |
|---|---|---|
| `obj` | 一样东西从边上滑进来停住（芯片、产品、车） | 抠好的透明 PNG |
| `pour` | 从右上伸进来，下半截从上往下露出来（倒水、撒东西） | 东西在右上、流下来的部分在左下 |
| `hammer` | 举起、砸在底座上、收走（拍板、敲定） | 槌头在左、柄朝右的横图；`block` 是底座 |
| `bills` | 一张张喷上来在空中翻（钞票、传单） | 一张平的图；`layer:'behind'` 放她身后，`big:true` 是镜头前虚的几张 |

图从哪来：真照片（Wikimedia Commons 的 CC0、公有领域）用 `scripts/cut_img.py` 抠；找不到就用 `scripts/gen_prop.sh` 生图（三维小道具、浅灰平底；第 4 个参数写这条片的颜色），再抠。出处记进 `assets/img/credits.json`。

**规矩**

| | 规矩 | 为什么 |
|---|---|---|
| 硬 | 屏上的原话、数字、人名都要核过出处 | 截图和引语是证据 |
| 硬 | 参数名、`props` 的 `kind` 写错会报错，不会悄悄丢掉 | 看不了图的模型发现不了画面少了东西 |
| 默认 | 颜色一个家族：一个主色（取自口播画面，管卡的底、细边、大字）加三个伴色（按主色自动配的青绿、杏橙、天蓝，饱和度压得低；一屏只有被强调的那一样是全色，其余灰一档），图形镜头里每样东西轮着用；自己做的卡只有一种（深色玻璃卡加浅色细边），白纸只留给真截图 | 参考片每条有一个主色，但柱子、徽章、表格行各有各的颜色，不是一屏一个色；混进别的风格（漫画描边、警戒条、金字棕边、荧光色）才会打架 |
| 默认 | 口播画面保持亮，不压黑渐变；东西做大、敢出框 | 参考片的口播是亮的，字直接压在亮画面上 |
| 默认 | 每个组件一条片用一两次，相邻两镜进场不重复 | 同一种砸法连着用，看着像套模板 |
| 默认 | 落定后不动：不弹、不晃、不飘、镜头不顿、口播不慢推 | 参考片量过，停住以后一个像素不动 |
| 默认 | 道具用真东西的抠图或生图，不用代码画 | 代码画的桶和槌像剪贴画 |

偏离"默认"可以，在导演表里写一行为什么。

**旧场景**：下面文档里的 `v-` 场景是上一代的画法，新片优先用 `vp-`：`v-host-words`→`vp-words`、`v-stack`→`vp-newspile`、`v-doc`→`vp-paper`、`v-title`→`vp-verdict` / `vp-ask`、`v-host-sides`→`vp-voices`、`v-host-num` / `v-number`→`vp-number`、`v-bars`→`vp-bars`、`v-vs`→`vp-versus`、`v-chain`→`vp-chain`、`v-list`→`vp-list`、`v-line`→`vp-line`、`v-quote`→`vp-quote`、`v-pie`→`vp-share`、`v-chapter`→`vp-chapter`、放图的 `v-full`→`vp-photo`。`vp-` 里没有的（实拍片段 `v-clip`、表格 `v-table`、手机截图 `v-phone` 这些）照旧用 `v-`，可以混在一条片里。

**检查全绿不等于片子好**：渲完用 `scripts/sheet.py` 把每镜的落定帧拼成联系表，和参考片的同类镜头放大并排看，写出差距再改（看亮度、颜色、大小、道具真假、落定后动不动）。

## 一屏长什么样

```
┌──────────────┐ 0
│              │
│   画面区      │  上面 82%（0–1574）：她在讲 / 素材 / 卡片 / 图表 / 大字
│              │
│  （字幕压在   │  字幕在 69%–73% 高，压在画面区下沿
│   这一带）    │
├──────────────┤ 1574  接缝正中是栏目小标（brand）
│   黑条        │  下面 18%：留给平台的标题、点赞按钮，不放东西
└──────────────┘ 1920
```

- 镜头之间只有硬切，不写 `enter`。
- 一镜只讲一件事。东西一句出一样（`items` 里每个写 `at:'@b03:词'`），出来了就留着，不闪走。
- 一镜 1.5–5 秒。她连续露脸超过 8 秒，要换景别（`zoom`）或者出东西。
- 证据镜（`v-clip` `v-doc` 这些）之后回到她，再去下一段证据。没有口播时，用 `v-title`、`v-number` 当"喘气"的地方。

## 五步出片

```
node scripts/new_film.mjs <片子目录> --vertical      # 建工程（想先看全部场景长什么样：--demo-v）
（写 script.json：一句一个 id，一个分句不超过 14 个字）
（时间线：有口播用 host_timeline.py，没有用 temp_voice.py 或 timeline_stub.mjs，和横屏版一样）
（写导演表，再写 film.js：每镜从下面的表里选场景）
node scripts/render.mjs --dir <片子目录> --check      # 查表：填错的参数、太短的镜头、放不下的字，都会用大白话告诉你怎么改
node scripts/render.mjs --dir <片子目录> --sheet      # 出联系表，看每一镜
node scripts/render.mjs --dir <片子目录> --video --h 1080 --workers 2    # 成片画面 1080×1920（预览用 --h 720）
python scripts/mix.py <片子目录> --check              # 混音，和横屏版一样
```

`--h` 写的是短边：竖屏 `--h 1080` 出来是 1080×1920。

## film.js 开头怎么写

```js
const K=await KIT.use(F);
await KIT_VERT.use(K,{
 skin:'dark',      // 'dark' 黑底图标底纹 + 白纸卡 + 立体厚字（财经、科技）/ 'paper' 灰紫底 + 米白卡 + 绿重点（生活、消费）
 pattern:'gold',   // 黑底上平铺的线条小图标，挑和题目沾边的：chart 走势 / gold 金条 / coin 钱 / oil 油桶 / car 车 / rocket 火箭 / bag 购物袋
 brand:'橙C',      // 接缝上的栏目小标，不要就写 ''
 host:{name:'host',fps:30,faceY:330,bright:1.15},   // 有口播才写，见下面"有口播"
});
await K.film([ /* 一镜一个对象 */ ]);
```

每一镜三样必写：`scene`（场景名）、`until`（到哪一刻结束，最后一镜不写）、`says`（这一镜让观众多懂了什么）。
时刻一律写 `'@句id'` 或 `'@句id:词'`（念到这个词的那一刻），不写秒数。

## 有口播

- 口播是横屏拍的也行：场景会自动把她裁进竖屏的画面区，脸放在画面 31% 高。
- 口播按原片帧率抽帧到 `assets/clips/host/0001.jpg…`（1920×1080），`assets/clips/counts.json` 里登记 `"host": 帧数`。
- `host:{name, fps, faceY, bright}`：`fps` 是口播原片的帧率；`faceY` 是她脸中心在原片（1080 高）里离上沿多少像素，拿一帧量一下；`bright` 是提亮倍数，室内拍的脸发暗就写 1.1–1.2。
- 有口播时，卡片类场景（第三组全部、`v-doc`）右上角会自动带她的圆头像，不想要就在那一镜写 `avatar:false`。
- 横屏口播裁进竖屏以后，景别 1.0 已经是最远，人还是比竖着拍的近。想要半身中景，只能竖着重拍。
- 她站得偏左或偏右：在 `zoom` 里写 `x`（`zoom:[{at:'@b01',s:1.15,x:-.2}]`）。
- 抠像（`assets/cut/host/`）不是必须的。只有 `v-host-num` 写了 `behind:true` 才用得到。
- 口播拍得太满（头顶贴边）时，`zoom` 别超过 1.2，不然头发会被裁掉。

## 没有口播

六个 `v-host` 开头的场景不能用，其余 23 个照常。对应换法：

| 有口播时 | 没口播时换成 |
|---|---|
| `v-host`（她说观点） | `v-title`（整屏大字） |
| `v-host-num` | `v-number` |
| `v-host-words` | `v-title` |
| `v-host-cards` | `v-list` / `v-data` / `v-vs` |
| `v-host-bubbles` | `v-stack`（没截图就写 title）/ `v-quote` |
| `v-host-sides` | `v-collage` / `v-brand` |

`v-clip` 的圆头像会自动不出。

## 先当导演，再填表

模板管的是"每一镜长什么样"。一条片好不好看，先看下面五件事定没定。填表之前用五行字写下来（写在 shots.md 开头），定不下来就先别填。

| 先定什么 | 怎么定 | 写错了会怎样 |
|---|---|---|
| 一句话 | 观众看完能转述给别人的那一句（"利率高了，黄金就吃亏"）。每一镜都要为它出力 | 每镜都对，连起来不知道在讲什么 |
| 最重的一镜 | 全片只有一个：答案出现的那一镜，或最大的那个数。给它 `hero:true`（进场多一下白闪和冲镜）、最大的字、一张专门生的图 | 镜镜都使劲，观众一个也记不住 |
| 轻重三档 | 重：整屏立体字、胸前大数（全片 2–3 次）。中：白纸卡、截图、实拍带。轻：她 + 一个标签 | 一路都是"中"，看着像幻灯片 |
| 呼吸 | 她说观点 → 最多 3 镜证据 → 回到她。连着两镜都是她，景别换一档。重的一镜前面放一镜轻的 | 证据连着轰，观众忘了谁在讲；或者她一直讲，没东西看 |
| 哪几处要图 | 因果链的每一环、整屏标题的窗、证据截图。先列出来去生图 / 截图，再填表 | 白板上只有色块，质感掉一档 |

`--check` 会替你查其中能数的几项：有没有标最重的一镜（多于一个也报）、她露脸占三成到六成、证据有没有连着超过 3 镜、连着两镜景别一样、因果链和整屏标题有没有图。查不了的是"一句话"和"轻重"，这两样要自己想。

这个 skill 用到头是这样：拿到一条口播，先找出那一句话和最重的一镜，其余的镜头都是给它们铺路。模板只是把铺路的活变成填表。

## 这句话在说什么 → 用哪个场景

先看左边一列找到这句话的意思，再用右边的场景。找不到完全对的，就用最近的；实在没有，用 `v-clip`（有画面）或 `v-list`（没画面）。

### 一、她在讲（要有口播）

| 这句话在说什么 | 场景 | 什么时候用 | 别这么用 | 最短 |
|---|---|---|---|---|
| 她对着镜头讲：开头打招呼、抛问题、说观点、结尾收话 | `v-host` | 没有别的东西要给观众看的句子；每段证据之后回到她 | 一口气超过 8 秒不换景别、不出东西 | — |
| 她一边讲，胸前一张一张出卡片：几个选项、几家公司、几个要点 | `v-host-cards` | 并列的 2–3 样东西，她念到哪个出哪个 | 超过 3 张（改 v-list）；卡上写长句 | 1.6 秒 |
| 她说出一个大数，数字拍在她胸前 | `v-host-num` | 这句话的主角是一个数：涨了多少、亏了多少、多少钱 | 一句里两个数（改 v-data） | 1.2 秒 |
| 她说到关键词，大字一个一个拍在她胸前 | `v-host-words` | 一句话里有 1–3 个要观众记住的词；反问、口头禅、结论 | 整句话都打出来（那是字幕的事） | 1.2 秒 |
| 她转述别人的话、网友的问题：气泡在她头两边冒出来 | `v-host-bubbles` | "有人说……""你可能会问……"；几种常见说法 | 气泡里写超过 14 个字 | 1.5 秒 |
| 她提到的人 / 公司，照片卡立在她两边 | `v-host-sides` | 讲到一两个当事人、两家对手 | 没有照片（改 v-host-cards） | 1.5 秒 |

### 二、把证据摆出来

| 这句话在说什么 | 场景 | 什么时候用 | 别这么用 | 最短 |
|---|---|---|---|---|
| 实拍 / 照片放在中间一条宽带里，上面一行标题，带子上叠标签、数字、人 | `v-clip` | 这句话有现成的画面可看：新闻现场、产品、当事人、地方 | 素材和这句话没关系（只为了不空着） | 1.2 秒 |
| 一张图 / 一段实拍铺满整个画面区，字压在上面 | `v-full` | 画面本身够震撼、够好看，值得整屏看；开场的第一眼 | 连着用两次；图上已经有很多字 | 1 秒 |
| 换话题：一张章节卡，告诉观众"下面讲第二件事" | `v-chapter` | 长片（60 秒以上）里两三个大段落之间 | 30 秒以内的短片；一条片超过 3 张 | 1 秒 |
| 一张梗图 / 表情 / 截图拍在中间，配一句吐槽 | `v-meme` | 调侃、自嘲、网友反应：让观众笑一下 | 一条片超过两次；严肃的数据 | 1 秒 |
| 把原文摆出来：新闻、财报、公告的截图放在白卡上，重点句刷黄 | `v-doc` | "据某某报道""财报里写着"：让观众看到出处 | 截图上的字小到手机上看不清（先裁到只剩那一段） | 1.5 秒 |
| 一条接一条的新闻 / 截图，啪啪啪摞上来：这事到处都在报 | `v-stack` | "最近全网都在说""一个月里出了三件事" | 每张要观众细读（改 v-doc） | 1.5 秒 |
| 几张照片拼在一起，一张一张贴上来：这一类东西长这样 | `v-collage` | 举几个例子（几款车、几个地方、几个人） | 超过 4 张；照片之间没有并列关系 | 1.5 秒 |
| 一部手机立在中间，屏幕里是 App / 网页 / 聊天截图，可以往下滑 | `v-phone` | "打开某某 App 你会看到""评论区都在问" | 横版截图（改 v-doc） | 1.5 秒 |

### 三、算账、比较、讲道理

| 这句话在说什么 | 场景 | 什么时候用 | 别这么用 | 最短 |
|---|---|---|---|---|
| 一张清单卡：几条原因 / 几个选项 / 几步，念一条出一条；最后可以落一块答案 | `v-list` | "有三个原因""要看这几样"；排除法（前几条打叉，最后一条是答案） | 超过 5 条；每条超过 14 个字 | 1.5 秒 |
| 几行"名字 + 数字"：左边是什么，右边是多少 | `v-data` | 一句话里报了 2–4 个数；几个指标并排看 | 只有一个数（v-number / v-host-num）；要比大小（v-bars） | 1.5 秒 |
| 横条比大小：谁多谁少一眼看出来 | `v-bars` | 几样东西比同一个数（销量、价格、占比） | 数字差不多大（比不出来）；超过 6 条 | 1.8 秒 |
| 上下两块对着比：A 是这样，B 是那样 | `v-vs` | 两种选择、两家公司、以前和现在 | 三样以上（v-table） | 2 秒 |
| 一个圆环分成几块：钱 / 人 / 份额是怎么分的 | `v-pie` | 占比、构成（加起来是 100%） | 超过 5 块；不是"构成"的数 | 1.8 秒 |
| 一个数原地变成另一个数：从多少到多少 | `v-move` | 涨了、跌了、砍半、翻倍：变化本身是这句话的意思 | 只有一个数（v-number） | 1.5 秒 |
| 一笔一笔加起来，底下落一个总数 | `v-sum` | 算账：几项成本、几笔收入加起来是多少 | 不是加法关系的几个数（v-data） | 2 秒 |
| 一张对比表：几样东西按几个方面比，一行一行出 | `v-table` | 三样以上的东西横着比；片尾的总结表 | 超过 4 列、6 行；格子里写句子 | 2 秒 |
| 一条走势线从左画到右：涨上去、掉下来，关键的点标出来 | `v-line` | 价格、利率、销量随时间的变化 | 只有两三个点（v-move） | 2 秒 |
| 因果链从上往下一环扣一环：因为 A，所以 B，所以 C | `v-chain` | 解释"为什么"：一步一步推过去 | 并列关系（v-list）；超过 4 环 | 2 秒 |

### 四、整屏大字、提问、品牌、引语

| 这句话在说什么 | 场景 | 什么时候用 | 别这么用 | 最短 |
|---|---|---|---|---|
| 整屏斜体大字：片名、一句核心问题、一句结论 | `v-title` | 开头抛问题；中间夹在两段证据之间的一句答案；全片最多三次 | 一行超过 7 个字；连着用 | 1 秒 |
| 一道选择题：先给选项让观众猜，再亮答案 | `v-quiz` | 开头勾人："你猜是哪个？"；反常识的事实 | 答案显而易见；一条片超过一次 | 2 秒 |
| 一墙色块：几家公司 / 几个品牌 / 几个国家，说到谁亮谁 | `v-brand` | "这个行业有这几家"；点名 | 超过 6 个；要比数字（v-bars） | 1.5 秒 |
| 一句引语：谁说的，原话是什么 | `v-quote` | 当事人、官方、报告里的一句关键原话 | 转述（直接让她说）；超过 30 个字 | 1.8 秒 |
| 整屏只有一个大数 | `v-number` | 全片最重要的那个数；没有口播素材时代替 v-host-num | 一条片超过两次 | 1.2 秒 |

## 每个场景怎么填

每个场景一段：必填项、全部参数、一行能直接抄的例子。例子里的 `scene` `until` `says` 每一镜都要写，后面不再重复说明。

### 一、她在讲（要有口播）

#### v-host

她对着镜头讲：开头打招呼、抛问题、说观点、结尾收话。

| 参数 | 写什么 |
|---|---|
| `zoom` | 景别：1.25 这样的数字，或 [{at:'@b02',s:1.3,x:0}] 中途硬切换档 |
| `name` | 名字条（第一次出场写一次） |
| `role` | 名字条第二行：身份 |
| `nameAt` | 名字条出现的时刻 |
| `caption` | 她头顶的一行小标题 |

```js
{scene:'v-host', until:'@b02', says:'先认识她，知道今天聊什么', zoom:1.15, name:'橙C', role:'今天聊黄金', nameAt:'@b01:最'},
```

#### v-host-cards

她一边讲，胸前一张一张出卡片：几个选项、几家公司、几个要点。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `items` | [{title, sub, img, value, color, at:'@b03:词'}]，最多 3 张（bar 最多 4 条） |
| `shape` | 'row' 半透明矮卡一排，title 是卡顶的小标签、value 是卡里的大字（默认）/ 'tall' 竖高卡（带图）/ 'bar' 横条一条一条往下摞 |
| `title` | 头顶一行小标题 |
| `zoom` | 景别，同 v-host |

```js
{scene:'v-host-cards', until:'@b10', says:'黄金没利息，美债有', items:[{title:'黄金', value:'0%', sub:'不生利息', color:'gold', at:'@b08'},{title:'美债', value:'4.9%', sub:'每年稳拿', color:'green', at:'@b09'}]},
```

#### v-host-num

她说出一个大数，数字拍在她胸前。

必填：`value`

| 参数 | 写什么 |
|---|---|
| `value` | '6.9%' '$104' '3.6亿' |
| `label` | 数字下面一行说明 |
| `at` | 数字出现的时刻 |
| `color` | 'red' / 'green'，默认金色 |
| `roll` | true = 从 0 滚到这个数 |
| `behind` | true = 数字放到她身后（要抠像；数字中间会被头挡住，只适合 5 位以上的长数） |
| `zoom` | 景别，同 v-host |

```js
{scene:'v-host-num', until:'@b05', says:'一个月跌了快 7%', value:'-6.9%', label:'10月跌幅', color:'red', roll:true, at:'@b04:跌'},
```

#### v-host-words

她说到关键词，大字一个一个拍在她胸前。

必填：`words`

| 参数 | 写什么 |
|---|---|
| `words` | [{text:'反而跌', at:'@b03:反而', hl:true}]，最多 3 个，每个不超过 6 个字；hl:true 的那个更大、金色；中文词会逐字错开一点大小和角度 |
| `zoom` | 景别，同 v-host |

```js
{scene:'v-host-words', says:'记住一个动作：先看利率', words:[{text:'先看一眼', at:'@b11:先'},{text:'利率', at:'@b11:利', hl:true}]},
```

#### v-host-bubbles

她转述别人的话、网友的问题：气泡在她头两边冒出来。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `items` | [{text:'乱世买黄金', mark:'？', at:'@b02:乱世'}]，最多 4 个；mark 是气泡角上的大符号（'？' '！'），这句话后面要被推翻就写 '？' |
| `zoom` | 景别，同 v-host |

```js
{scene:'v-host-bubbles', until:'@b03', says:'大家都信这句老话', items:[{text:'乱世买黄金', mark:'？', at:'@b02:乱'}]},
```

#### v-host-sides

她提到的人 / 公司，照片卡立在她两边。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `items` | [{img, name, tag, at}]，1–2 张：第一张在左，第二张在右 |
| `zoom` | 景别，同 v-host |

```js
{scene:'v-host-sides', until:'@b06', says:'两个当事人是谁', items:[{img:'assets/img/a.jpg', name:'鲍威尔', tag:'美联储主席', at:'@b05'},{img:'assets/img/b.jpg', name:'特朗普', tag:'要他降息', at:'@b05:特'}]},
```

### 二、把证据摆出来

#### v-clip

实拍 / 照片放在中间一条宽带里，上面一行标题，带子上叠标签、数字、人。

| 参数 | 写什么 |
|---|---|
| `clip` | 实拍帧序列名（assets/clips/<名字>/） |
| `img` | 或者一张图 |
| `from` | 实拍从第几秒开始 |
| `rate` | 倍速 |
| `pos` | 裁切位置，如 '50% 20%' |
| `title` | 带子上面的标题（可以用 \n 分两行，<em>重点</em>） |
| `brow` | 标题上面的小字 |
| `tags` | 带子上的白底标签，一句出一个，留着不走：[{text:'售价 3 万', at:'@b03:三万'}] |
| `num` | 带子中间的大数字，可以原地变：{from:'$209', to:'$108', at:'@b04:跌', label:'油价'} |
| `person` | 右下角的抠像人：{img:'x.png', name:'某某', grayAt:'@b05'}（grayAt 之后变灰 = 出局） |
| `strip` | 带子底下的一排小格：[{title:'成本', value:'$2万', at}]，最多 4 格 |
| `avatar` | 角上要不要她的圆头像（有口播时默认要，false 关掉） |
| `source` | 素材来源小字 |

```js
{scene:'v-clip', until:'@b03:黄', says:'这次是真在打仗', clip:'smoke', title:'这次<em>真在打</em>', tags:[{text:'油价冲上 $104', at:'@b03:打'}], source:'新闻实拍'},
```

#### v-full

一张图 / 一段实拍铺满整个画面区，字压在上面。

| 参数 | 写什么 |
|---|---|
| `clip` | 实拍帧序列名 |
| `img` | 或者一张图 |
| `from` | 实拍从第几秒开始 |
| `rate` | 倍速 |
| `pos` | 裁切位置 |
| `title` | 压在上面的标题 |
| `brow` | 小字 |
| `tags` | 标签，同 v-clip |
| `avatar` | true = 左下角放她的圆头像 |
| `dim` | 压暗多少（0–1，默认 .25） |
| `source` | 来源小字 |

```js
{scene:'v-full', until:'@b02', says:'第一眼：这地方长这样', img:'assets/img/port.jpg', title:'全球最大的<em>免税店</em>', brow:'海南 · 三亚'},
```

#### v-chapter

换话题：一张章节卡，告诉观众"下面讲第二件事"。

必填：`title`

| 参数 | 写什么 |
|---|---|
| `no` | 序号 '01' |
| `title` | 这一段的名字 |
| `sub` | 一行补充 |

```js
{scene:'v-chapter', until:'@b12', says:'换话题：下面讲谁在赚钱', no:'02', title:'谁在赚钱', sub:'三家公司分蛋糕'},
```

#### v-meme

一张梗图 / 表情 / 截图拍在中间，配一句吐槽。

必填：`img`

| 参数 | 写什么 |
|---|---|
| `img` | 图片 |
| `caption` | 图下面的一句话（大字） |
| `title` | 图上面的标题 |
| `brow` | 小字 |
| `rot` | 歪几度（默认 -2） |

```js
{scene:'v-meme', until:'@b07', says:'笑一下：网友的反应', img:'assets/img/meme.jpg', caption:'我的钱包：？'},
```

#### v-doc

把原文摆出来：新闻、财报、公告的截图放在白卡上，重点句刷黄。

必填：`img`

| 参数 | 写什么 |
|---|---|
| `img` | 截图（先裁好） |
| `title` | 上面的标题 |
| `brow` | 小字（如 来源名） |
| `hl` | 刷黄的地方：[{x:.1,y:.3,w:.8,h:.08,at:'@b04:最低'}]，x y w h 是占截图宽高的比例 |
| `zh` | 外文原文的中文：{text:'黄金跌到一年多来最低', at} |
| `source` | 来源小字 |
| `pos` | 截图太长时显示哪一段（0 顶部–1 底部） |
| `flat` | true = 截图平着放（默认斜放，上下边虚一点） |
| `avatar` | 角上要不要她的圆头像（有口播时默认要，false 关掉） |

```js
{scene:'v-doc', until:'@b08', says:'原文写着 12 月还要加息', img:'assets/img/doc_cnbc.png', brow:'CNBC 报道', title:'市场怎么押', hl:[{x:.04,y:.35,w:.87,h:.1,at:'@b07:可'}], zh:{text:'12 月再加息：<em>75%</em> 概率', at:'@b07:还'}},
```

#### v-stack

一条接一条的新闻 / 截图，啪啪啪摞上来：这事到处都在报。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `items` | [{img:'截图', at}] 或没有截图时 [{title:'新闻标题', source:'媒体名', at}]，3–5 张，每张约 1 秒 |
| `title` | 上面的标题 |
| `brow` | 小字 |

```js
{scene:'v-stack', until:'@b04', says:'这事到处都在报', title:'一周三条大新闻', items:[{title:'金价跌破 3900', source:'路透'},{title:'美联储再放鹰', source:'彭博'},{title:'油价重回 100 美元', source:'CNBC'}]},
```

#### v-collage

几张照片拼在一起，一张一张贴上来：这一类东西长这样。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `items` | [{img, label, at}]，2–4 张 |
| `title` | 上面的标题 |
| `brow` | 小字 |

```js
{scene:'v-collage', until:'@b05', says:'这一类车长这样', title:'都是<em>两座小车</em>', items:[{img:'assets/img/c1.jpg', label:'Smart'},{img:'assets/img/c2.jpg', label:'宏光 MINI'},{img:'assets/img/c3.jpg', label:'菲亚特 500'}]},
```

#### v-phone

一部手机立在中间，屏幕里是 App / 网页 / 聊天截图，可以往下滑。

必填：`img`

| 参数 | 写什么 |
|---|---|
| `img` | 竖版截图 |
| `scroll` | 这一镜里往下滑多少（占截图高度的比例，0–1） |
| `title` | 上面的标题 |
| `brow` | 小字 |
| `tags` | 手机两边的标签：[{text, at}]，左右交替，最多 4 个 |

```js
{scene:'v-phone', until:'@b06', says:'评论区都在问同一件事', img:'assets/img/comments.png', scroll:.3, title:'评论区', tags:[{text:'还能买吗', at:'@b05:买'},{text:'要不要卖', at:'@b05:卖'}]},
```

### 三、算账、比较、讲道理

#### v-list

一张清单卡：几条原因 / 几个选项 / 几步，念一条出一条；最后可以落一块答案。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `title` | 卡片上面的标题 |
| `brow` | 小字 |
| `items` | [{text:'打仗推高油价', sub:'小字补充', mark:'no'\|'ok', hl:true, at:'@b06:油价'}]，2–5 条 |
| `answer` | 最底下的答案块：{text:'问题出在利率', at:'@b05:利率'} |
| `source` | 来源小字 |

```js
{scene:'v-list', until:'@b09', says:'三个原因，最后落到利率', title:'为什么跌？', items:[{text:'打仗推高油价', at:'@b06'},{text:'通胀压不住', at:'@b06:通'},{text:'美联储加息', at:'@b07', hl:true}], answer:{text:'问题出在利率', at:'@b08'}},
```

#### v-data

几行"名字 + 数字"：左边是什么，右边是多少。

必填：`rows`

| 参数 | 写什么 |
|---|---|
| `title` | 标题 |
| `brow` | 小字 |
| `rows` | [{label:'通胀', value:'3.6%', note:'小字', color:'red'\|'green', hl:true, at}]，2–4 行 |
| `source` | 来源小字 |

```js
{scene:'v-data', until:'@b07', says:'两个数说明通胀回来了', title:'现在的美国', rows:[{label:'油价', value:'$104', color:'red', at:'@b06'},{label:'通胀', value:'3.6%', color:'red', at:'@b06:通'}], source:'美国劳工部'},
```

#### v-bars

横条比大小：谁多谁少一眼看出来。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `title` | 标题 |
| `brow` | 小字 |
| `items` | [{label:'黄金', value:'-6.9%', color:'gold', hl:true, at}]，2–6 条 |
| `source` | 来源小字 |

```js
{scene:'v-bars', until:'@b05', says:'黄金跌得最多', title:'10 月谁跌得多', items:[{label:'黄金', value:'-6.9%', color:'gold', hl:true},{label:'美股', value:'-4.1%'},{label:'美元', value:'+2.3%', color:'green'}]},
```

#### v-vs

上下两块对着比：A 是这样，B 是那样。

必填：`left`、`right`

| 参数 | 写什么 |
|---|---|
| `title` | 标题 |
| `brow` | 小字 |
| `left` | 上面那块：{title:'存银行', value:'4.9%', sub:'每年有利息', color:'navy', img} |
| `right` | 下面那块，同上；再写 at（它出现的时刻） |
| `verdict` | 最后的结论块：{text:'利率越高越吃亏', at} |

```js
{scene:'v-vs', until:'@b10', says:'一个没利息，一个每年 4.9%', title:'钱放哪', left:{title:'买黄金', value:'0%', sub:'不生利息', color:'gold'}, right:{title:'买美债', value:'4.9%', sub:'每年稳拿', color:'green', at:'@b09'}, verdict:{text:'利率越高，黄金越吃亏', at:'@b09:拿'}},
```

#### v-pie

一个圆环分成几块：钱 / 人 / 份额是怎么分的。

必填：`items`

| 参数 | 写什么 |
|---|---|
| `title` | 标题 |
| `brow` | 小字 |
| `items` | [{label:'利息', value:60, color:'gold', at}]，2–5 块，value 是数字 |
| `center` | 环中间的字 |
| `source` | 来源小字 |


## 通用写法

- **颜色**：`color` 写名字：`'gold'` `'red'` `'green'` `'navy'` `'steel'`。数字涨跌用 `red` / `green`，其余默认金色。
- **重点字**：标题、引语里用 `<em>重点</em>` 包住要变色的词，一行最多一处。
- **数字**：照口播里的写法写成字符串：`'6.9%'` `'-6.9%'` `'$104'` `'3.6亿'`。负号写在最前面。
- **时刻**：`at:'@b03:词'`。不写 `at` 的 `items` 会在这一镜里均匀排开；`'@b07:1+0.3'` 是"b07 第 1 个字之后再等 0.3 秒"。
- **截图先裁**：`v-doc` 的截图先裁到只剩要看的那一段（宽高比 1.5:1 到 3:1 最好），再量 `hl` 的比例。整页截图放进去，字小到手机上看不清。
- **标签别抄字幕**：`tags`、`label` 写字幕里没有的信息（一个数、一个地名、一个来源）。和字幕一模一样等于没写。
- **占位素材**：`assets/kit/ph/` 里的图只为先跑通，成片前全换掉，`--check` 会提醒。

## 一条片怎么排（照这个配比不会错）

排法看自三条参考片（每条 5–8 分钟，各看了开头、中段、结尾的镜头单）：

| 位置 | 放什么 | 例子 |
|---|---|---|
| 开头 0–5 秒 | 她全屏直接开口，或一张最反常的图 / 一个问题 | `v-host` / `v-full` / `v-quiz` / `v-title` |
| 每一段 | 她说观点 → 1–3 镜证据 → 回到她 | `v-host` → `v-clip` `v-doc` `v-line` → `v-host-words` |
| 大数出现 | 单独给一镜 | `v-host-num` / `v-number` / `v-move` |
| 讲"为什么" | 一条链或一张清单 | `v-chain` / `v-list` |
| 60 秒以上换话题 | 章节卡 | `v-chapter` |
| 结尾 | 她全屏，一句大白话；关键词拍在胸前 | `v-host-words` / `v-title` |

- 她露脸的时间大约占四成；一条 30 秒的片 10–14 镜（这两个数是按镜头单估的，不是逐帧量的，当参考）。
- 同一个场景不要连着用两次（`v-host` 换景别不算）。
- 整屏大字（`v-title`）全片最多三次；梗图最多两次；选择题最多一次。

## 常见报错

| `--check` 说 | 怎么改 |
|---|---|
| 没有这个场景 | 场景名写错了，竖屏的都以 `v-` 开头，对着上面的表改 |
| 缺必填项 | 看上面那个场景的"必填" |
| 这一镜只有 x 秒，至少要 y 秒 | 把 `until` 往后挪一句，或者把这一镜和前一镜并掉；只差 0.2 秒以内可以不改 |
| 字太多放不下 | 按提示的字数删；长句交给字幕，屏上只留词 |
| 找不到图 / 实拍 | 路径从片子目录写起：`assets/img/x.png`；实拍要在 `counts.json` 登记 |
| 用了占位素材 | 成片前换成真素材 |

## 质感靠图：这几样先生图再填

和参考片并排比，差距最大的不是版式，是"有没有图"。下面三处不要拿代码画的扁平示意顶，先生图（或找图）：

| 用在哪 | 要什么图 | 生图时怎么说 |
|---|---|---|
| `v-chain` 每一环的 `img` | 白底小插画，一环一个物件（油桶、购物车、央行大楼） | 纯白背景、单个物件居中、扁平淡彩、不带字、方图 |
| `v-title` 的 `pic` | 横图，暗底，一个和关键词对应的物件（百分号雕塑、金条） | 深色背景、金属质感、物件居中偏上、四周留空、不带字 |
| `v-doc` 的 `img` | 真的报道 / 财报截图，裁到只剩标题和那两三行 | 不生图，去原网页截 |

插画拿到以后把底色推成纯白再用（不然白板上会露出一块灰方块）。截图里要划荧光笔的那句，别放在最右边 10% 里：截图是斜着放的，右边会收窄。
