# 镜头怎么接

每个边界先回答“上一镜留下什么、下一镜要看什么、靠什么接”，再从下面挑一种走法。下面写的是机制和什么时候用；画面每条片现写。走法只交接注意力，不带新信息，也不挪动配音和字幕的时间点。原理和量化目标在 `motion.md`。

标了 `M.xxx` 的走法，`scripts/moves.js` 里有现成的动作。意思对得上才用，只是差不多就手写（`motion.md` 的手法库）。

## 动作的手感（全片统一）

- **动的是镜头**：一镜的机位 = 起点 + 几次移动 + 中间慢漂。
  - 移动 0.5–1.1 秒，ease-in-out；落点就是正在讲的那个东西；
  - 两次移动之间慢漂，多半往里推。参考片约 3%/秒；`camPath` 的 drift 填 0.016–0.025 就能量到这个数。
  - 用 `scripts/stage25d.js` 的 `camPath`。
- **有前后层**：底 z≈0.3、字 z≈0.7、人和图形 z=1、前景 z>1。镜头一动，远的动得少。
- **快就带运动模糊**：按这一帧挪了多少像素加方向模糊（`L()` 自动算）；停下就清楚。
- **东西自己出现得很朴素**：淡入约 0.25 秒（可以带十几像素的位移），或者切过来时已经在。巨字可以 0.3 秒从 1.12 倍长到 1。不回弹、不过冲、不打字机、不扫光。
- **状态变化代替入场**：变亮、变灰、变色、被套住、被点亮，都是在原地发生。
- 时长：小元素 0.2–0.35 秒；换焦点或重新取景 0.5–1 秒；横推、甩入 0.3–0.4 秒。

## 走法

**带过：同一个对象跨镜头**
- 7250 亿：从四张新闻卡上累加出来 → 缩成片名的眉题 → 回到画面中间当锚（底下实拍在换）→ 升到上方分出两条线 → 结尾立成红柱 → 被四家押注。
- 要求：身份、颜色、比例不变；在上一镜的末态里已经在，下一镜一开场就在。

**钉住一个东西，底下换实拍**（`M.montage`）
- 片名和 7250 亿钉在中间，底下的数据中心实拍（压暗、去色）0.42 秒换一座，一直换到“芯片”两个字出来。
- 也可以把上一镜的圆盘缩成徽章钉在角上，底下连切几镜实拍。

**沿着桌面滑过去：念到哪个，镜头到哪个**
- 四家的新闻卡平铺在一张透视桌面上，念到谷歌、微软、亚马逊、Meta 时，镜头沿桌面滑到那一张（0.4 秒），念到才亮，没念到的压暗；“这四家”抬高看全。
- 比“一张张砸到最上面”好：东西早就在，镜头去找它。

**平面倒成桌面**（`M.layFlat` + `M.standUp`）
- 前面的东西讲完了、还要留作背景时，整层转到透视平面上（约 60°）、下沉、压暗到 0.3，新的主角从下面立起来。
- 例：“加起来”时四张卡倒平、退成底，7250 亿立在上面滚；路透原文倒平，累计净烧的图表立在上面。

**推近：画框变成下一镜**（`M.frameFill`）
- “芯片”画框推满屏（0.45 秒，中间略虚）→ 黄仁勋台上的实拍从 1.08 倍收到 1 →“卖芯片的英伟达”。推近的是同一份东西，不换成一张相似的图。

**人身后换背景**（`M.bgSwap`）
- 先放实拍原片；说到关键词那一帧，同一个人的抠像压到新底上，位置和原片一模一样，看不出接缝；巨字在他身后长出来；再用 0.6 秒把人挪到构图位置、放大（`cutP` 的 track 从 0 走到 1）。
- 例：“市值”时黄仁勋身后的舞台换成英伟达的绿，“5.2 | 万亿”分在他头两侧。

**人站在巨字前面，字随话翻**（翻字用 `M.megaFlip`）
- 同一个人、同一个底，字换一句：“全世界最值钱”时“5.2 万亿”往下滑出、“全球第一”从上面落下（0.24 秒，竖向模糊）。挑原片里有动作的那一段对上这句（他正好张开双手）。

**横推换人**（`M.pushSwap`）
- 整组（底 + 字 + 人）0.4 秒横推出画，新的一组从另一边推进来，两组都带方向模糊。新一组的底换成这家的颜色。
- 例：黄仁勋连字带人往左推走，Altman 带着青色的底推进来。

**卡片在人旁边冒出来，焦点移过去**（`M.cardFocus`）
- 说到“收入”时，Altman 肩旁冒一张小卡“$360 亿”（淡入加一点上移）；同时他身后的“8520 亿”虚掉、压暗一半，镜头往卡片那边挪一点。大字和小卡同框，大小对比自己说话。

**底下换成实拍**
- “光是算力”：图表缩到左边；它身后的桌面换成星门工地的实拍（压暗），8560 亿立在右边，和左边的 2780 一比，不用说出来。

**上一镜虚化当底**（`M.blurToBase`）
- 工地实拍 0.45 秒里模糊到约 26px、压暗到 0.4，退成资金循环桌面出现的那一刻。用在两个世界之间、又没有对象可带的时候。

**同一个世界里换机位：镜头去找正在说的那一个**（机位用 `S25.camKeys`，桌面用 `S25.desk3d`）
- 资金循环：
  - “从哪来”在 OpenAI 上慢漂；
  - “英伟达”时镜头摇过去找到它（它一直在桌上，只是在画外）；
  - 钱流到哪，镜头跟到哪；
  - “转了一圈”拉回看全；
  - “回到英伟达手里”推到英伟达，其余压暗。
- 机位用关键帧表（时刻 → x、y、z），两点之间 ease-in-out，最后一个点之后继续慢推。

**证据小卡：从相关的地方弹出来，看完缩回去**（`M.popWindow`）
- “英伟达投钱给 OpenAI”：CNBC 的实拍从“投资”箭头旁边弹成一张白边小卡，背景压暗；读完缩回箭头，桌面没有离场。不要切成全屏打断这张关系图。

**人 ↔ 圆盘、盘撑开成窗口**
- 实拍缩成盘：`clip-path: circle()` 把全屏实拍收到盘的半径，圆心同时挪到盘的位置，盘在后半段淡入。
- 盘撑开成窗口（`M.popWindow`）：钱回到英伟达后，从盘的位置把黄仁勋的原声窗口撑开（大小、圆角、位置一起变），说完再缩回。盘在屏幕上的位置要在渲出来的帧上实测，镜头推近以后它不在原坐标。

**镜头沿着差距走**
- 柱状图从低机位拍：红柱长出来时镜头跟着往上；“收回来的”摇到旁边那根矮柱；“差着一大截”镜头沿着差的那一段往上抬，括号跟着画出来。
- 镜头推近时，柱子下面的说明字收掉，免得压字幕。

**推过镜头：换舞台时，上一镜的末帧冲过来**（`M.pushThrough`）
- 上一镜最后一帧放大到 1.3–1.7 倍、模糊 12–14px、淡出（0.25–0.3 秒），盖在新一镜上。
- 结尾 Meta 筹码推过镜头接扎克伯格本人，放大中心对准那枚筹码，放大到 4 倍。

**押注：开头的东西在结尾回来**
- 开头那四家公司的 logo，在“大家都在赌”时一枚枚沿地面推到差额那一段上；“连扎克伯格自己都说”时只有 Meta 亮起，镜头推过去。首尾呼应，不需要解释。

**开头钩子**（关键词快闪、一个数砸下来、反差并排、悬念循环……）：每条片选一种，见 `opening.md`。

## 走法 → 模板里怎么写（模板档）

模板档里，镜头之间怎么接只有两种写法：这一镜的 `enter`，或者下一镜一开场就放上一镜留下的那样东西（"带过"）。`enter` 只有这几个：`cut`（默认）`flat` `push` `push-right` `through` `blur` `whip` `whip-left` `fade`。同一种不连着用（`--check` 会提醒）。

| 走法 | 模板里怎么写 |
|---|---|
| 带过：同一个对象跨镜头 | 没有专门的参数，下一镜的参数里写同一个东西。同一个数：`number` 的 `value` → `title` 的 `brow` → `montage`/`frames` 的 `pin`（`kit/demo/film.js` 第 3–5 镜）；同一个人：先 `person`，之后的 `discs` 用他的 `photo`；同一家公司：每一镜同一个 `color` |
| 钉住一个东西，底下换实拍 | `montage`（`pin` + `items`）、`title`（`items`；只给一段实拍就连续放，实拍退成底）；上一镜的圆盘钉在角上：`footage` 的 `badge` |
| 沿着桌面滑过去 | `desk`：`items[].at` 念到哪张滑到哪张，`all` 抬高看全；念到证据时 `read:{i, at}` 把桌面抬平、推近刷黄那一张的 `hl`（`kit/demo/film.js` 第 18 镜） |
| 平面倒成桌面 | 下一镜 `enter:'flat'`，接 `number`（数从下面立起来）或 `chart`（图表从桌面上立起来）（`kit/demo/film.js` 第 3 镜、第 10 镜）。能接 flat 的只有 `number` `chart` `equation` `change` `stats` 和不带 `items` 的 `title` `statement` |
| 推近：画框变成下一镜 | `frames` 的 `fill:{i, at}` + 下一镜同一份素材的 `footage`，写 `settle:true`（`kit/demo/film.js` 第 5–6 镜） |
| 人身后换背景 | `person` 的 `from:{img, at}` |
| 人站在巨字前面，字随话翻 | `person` 的 `words` + `flip` |
| 横推换人 | 下一镜 `enter:'push'`，两镜都是 `person` |
| 卡片在人旁边冒出来 | `person` 的 `cards` |
| 底下换成实拍（图表缩到一边，身后换工地实拍） | 没有模板：`custom` |
| 上一镜虚化当底 | 下一镜 `enter:'blur'` |
| 同一个世界里换机位 | board 系列：节点的 `at`，`steps` 的 `focus` / `light` / `show` |
| 证据小卡 | board 系列 `steps` 的 `pop:{img 或 clip, from, back}`（`kit/demo/film.js` 第 11 镜）；别的场景之后用 `scene:'popup'`：上一镜冻住压暗、窗口撑开（`kit/demo/film.js` 第 19 镜，接在新闻桌面后面，从"追着问"开始） |
| 人 ↔ 圆盘、盘撑开成窗口 | 盘撑开成窗口：`pop` 的 `from` 写他的圆盘 id，`clip` 放他的原声实拍；实拍缩成盘：没有模板，`custom` |
| 镜头沿着差距走 | `bars` 的 `gap`；排行榜：`ranking` 的 `climb` |
| 推过镜头 | 下一镜 `enter:'through'`，`throughAt:[x,y]` 对准要冲进去的那个东西 |
| 押注：开头的东西在结尾回来 | 用"带过"：结尾那一镜再用开头那几家的 `photo` 和 `color`；推过去的动作手写 |
| 开头钩子 | `flash`、`headlines`、`number`、`versus`、`equation`……按这条片的料选，见 `opening.md` 和 `rules.md` 的决策表 |

## 别这样

- 每个切点都套一个特效。
- 元素各自演入场：一个个弹出来排队、整体重排、贴上皇冠和徽章。
- 一整张平面一起缩放当“运镜”，或者镜头没有目标地往外拉。
- 东西摆好以后整屏定住两三秒以上。
- 连续硬切几次，每次都要观众重新找位置。
- 用闪白、飞纸、通用遮罩去盖一个没有理由的切换。
- 东西凭空出现：新东西要从它来的地方进场（箭头、上一个数、画框），或者本来就在、镜头去找它。
