# 动效：为什么参考片不像 PPT、不像 AI

下面的结论来自：三条同类参考片全片逐帧量镜头运动（去掉整屏主持人，只比 B-roll），23 段关键动作拆成连续帧，再和示例片被否的早期版本逐项对比。
参考片的连续帧不随仓库提供。想看某个动作怎么走，拿你自己的参考片用 `scripts/strip.py` 拆成一个动作 8 张的连续帧对照。

## 一句话

**参考片的"动"，是镜头在一个有前后层的世界里走、东西在原地换状态，每一下都对着那句话的意思。PPT 的"动"，是每个元素自己演一段入场动画、整张平面一起缩放。**
**AI 味来自两样：假装真实的通用大片当墙纸（熔炉、赌场、芯片神殿），和什么都在发光。**

慢推、数字滚动、实拍上压字，参考片都在用。示例片早期把这几样当成禁令，片子就死了：问题不在手法，在做法。

## 做每个动作前问三句

1. **删掉它，观众少懂了什么？** 什么都没少，就是装饰，删。
2. **是镜头在走、东西在换状态，还是元素自己在演入场？** 元素自己演，就改成镜头运动或者状态变化。
3. **这一层是真的、具体的东西吗？** 假装真实的氛围图，换成真素材，或者换成明说是设计出来的抽象底。

这是判断标准，不是禁令。

## 五条原理

**1. 动的是镜头和世界，不是元素。**
东西出现得很朴素：淡入约 0.25 秒，或者切过来时已经在那儿了。大运动交给镜头：在同一张关系图里推到一个节点、拉回全局、摇到旁边。或者交给原地换状态：小圆盘被大圆盘套住（= 收购）、节点变灰（= 出局）、连线变红（= 风险）。
早期的做法：圆盘一个个弹出来排一排，再整体重排成田字格；皇冠、NO.1 贴上去；数字带模糊砸进来。

**2. 每一下动作都是内容。**
推近 = 看这个，拉远 = 整体是这样，嵌套 = 吞下，换背景 = 现在说到这个世界，横推换人 = 换一个人说。删掉动作，意思就少一块。

**3. 有空间：前后层、景深、运动模糊。**
一帧里有好几层：远处的底纹、上一镜退成的虚化背景、图形、抠出来的人、前景的烟或粒子。镜头一动，远的动得少、近的动得多。快的东西带方向模糊，不讲的东西压暗、去饱和或者虚掉。
早期的做法：所有东西在一个平面上，一推全部同比例放大。镜头在动时，"各处动得不一样"的比例只有 30%，参考片是 52–62%。

**4. 节奏来自剪辑，不来自特效。**
一镜的节奏：快速换位（0.5–1 秒，两头缓、中间快）→ 慢漂（约 3%/秒，多半往里推）→ 下一刀。B-roll 大约 2 秒换一个画面，几乎没有超过 2 秒完全不动的时候。
早期的做法：一镜 4–6 秒，靠元素入场撑场面；或者东西摆好以后整屏定住 2–9 秒。

**5. 一个画面一个主角，其余让路。**
正在讲的那个亮着，其余压暗、去饱和或者虚掉。早期的做法：圆盘、数字、名牌、背景灯光一起发光，同样的强调等于没有强调。

## 为什么不像 AI

- **真东西当主角。** 人、地方、文件都是真的。生成的东西只演一个拍不到的具体比喻：蛇吞象、两栋只差招牌的楼、稳定币。生成物件要和真素材同光、同调色，有投影、有景深，放进同一个空间里。
- **背景要么是设计出来的抽象世界，要么就是内容本身。** 一条片定一片抽象底（深色织物、这一段的品牌色光），不假装是真实场景。实拍出现时，实拍就是在讲的东西。
- 早期的做法：熔炉、赌场、芯片神殿、夜景园区这类 AI 写实大片，压暗后垫在所有图形底下。

## 三个最容易做坏的手法

**数字滚动**
- 只在"累加、越来越多"本身就是意思的时候滚：几家加起来、按年份累计、一笔笔流进来。一条片最多一两次。
- 写满位数（`$725,000,000,000`），跳动的位数本身在说"有多大"。滚的时候按十亿取整，后面全是 0（参考片也是这样），不要出现 `$565,771,715,768` 这种乱码一样的数。
- 起点要有意思：从第一笔开始（比如第一家的 1800 亿），不从随便一个数开始。
- 话说到那个数时正好停，停下的那一刻配一声低沉的撞击。
- 滚的数放进场景里：前面的东西倒成桌面当底，数字立在上面。
- 早期的做法：每个数都滚，从 3332 滚到 8520。"八千五百二十亿"这句话本身没有累加，滚它就是装饰。

**实拍上压字**
- 只有两种压法：
  - **人在字前面**：把人抠出来，巨字夹在人和底中间，人站在两组字的空当里，字只有一两个词。字和人是一张海报，人还在动。
  - **实拍退成底**：实拍压暗（亮度约 0.36）、去色（约 0.5）、略虚（约 1px），字是主角。片名、章节卡、开头的钉字都这样。
- 早期的做法：在清楚的实拍上贴名牌框（电视台下三分之一模板），或者把字放在 AI 墙纸上。

**慢推**
- 推是机位朝一个目标在走，目标就是正在讲的那个东西。场景有前后层，推起来才有空间感。先快速推到位，再慢慢漂。
- 早期的做法：整张平面一起缩放，没有目标，多半在往外拉，每一镜都一样。

## 量化目标（交片前用 `scripts/motion_check.py` 量）

| 指标 | 参考片 B-roll | 早期第一版 | 早期第五版 | 重做后 |
|---|---|---|---|---|
| 画面完全不动的时间 | 15–29% | 42% | **66%** | 20% |
| 定住超过 2 秒 | 0.6–1.0 次/分 | 2.0 | **3.9** | 0 |
| 镜头在动的时间 | 21–27% | 19% | 10% | 24% |
| 镜头动时各处动得不一样 | 52–62% | **30%** | — | — |
| 有前后层的镜头运动 | 9–12% | **2.8%** | 7% | 10% |
| 往里推 : 往外拉 | 1.3–2.9 : 1 | **0.4 : 1** | 1.2 : 1 | 2.1 : 1 |
| 慢漂速度（缩放中位） | 2.8–3.6 %/秒 | 3.8 | 5.9 | 3.0 |
| B-roll 一镜时长 75 分位 | 2.4–3.0 秒 | **5.8** | 5.3 | 3.0 |

数字过了不等于好看，只说明不死、不平。数字没过，一定有问题。不要为了过线加闪动和抖动：每一下动作还是要过上面的三句话。

## 手法清单

按"这句话在说什么"选，不是挨个用一遍。参数是起点。

| 手法 | 它在说什么 | 怎么做 |
|---|---|---|
| **人抠像压巨字** | 这个人 = 这个词（市值、估值、帝国、权） | 实拍逐帧抠人（`scripts/matte.py`）；三层：底（z≈0.3）→ 巨字（z≈0.7）→ 人（z=1）；人钉在画面中间（按每帧头肩中心跟住他），字分两组放在他头的两侧；字在 0.3 秒里从 1.12 倍长到 1；镜头慢推 |
| **人身后换背景** | 话题换到另一个世界，人还是那个人 | 先放实拍原片；说到关键词那一帧，同一个人的抠像压到新底上（位置一模一样，看不出接缝），再用 0.6 秒挪到构图位置、放大 |
| **横推换人** | 换一个人、换一件事 | 整组（底 + 字 + 人）0.4 秒横推出画，新的一组从另一边推进来，两组都带方向模糊 |
| **卡片在人旁边冒出来** | 他说的这几样东西 | 跟着字出现，淡入 0.25 秒加一点上移；同时焦点从巨字挪到卡片（巨字虚掉、压暗），镜头往卡片那边挪一点 |
| **东西拿在手上** | 他手里握着这个 | 抠像加素材贴纸，挂在手的位置，素材自己有小动作（转、闪） |
| **钉住一个东西，底下换实拍** | 这件事 = 这些画面 | 前景（标题、数字、圆盘徽章）不动，底层实拍 0.4–1 秒一刀，压暗去色 |
| **同一个世界里换机位** | 看这个 → 看整体 → 看旁边 | 2.5D 相机：一镜一个落点，落点就是正在讲的那个；新东西在世界里早就摆好了，镜头摇过去"找到"它，而不是它滑进来；移动 0.6–1.1 秒，两头缓；中间慢漂 |
| **平面倒成桌面** | 前面的东西退成背景，新东西站在上面 | 整层转到透视平面上（rotateX 约 60°）、下沉、压暗到 0.3；新主角（图表、数字）从下面立起来 |
| **甩出 / 推进来** | 换一个画框、换一个对象 | 0.25–0.35 秒位移，配方向模糊（SVG `feGaussianBlur stdDeviation="x 0"`，按这一帧挪了多少像素挑档） |
| **上一镜虚化当底** | 从全局里拎出一个人或一件事 | 上一镜最后一帧模糊约 20px、压暗到 0.4，0.4 秒里退成新一镜的底 |
| **镜头沿着差距走** | 差得有多大 | 柱状图镜头从矮柱摇到高柱顶，或者沿着差的那一段往上抬；括号跟着镜头画出来 |
| **真火、烟、粒子叠层** | 章节的情绪、揭晓的一下 | 真实素材用滤色叠加；只在章节卡和揭晓处用 |
| **生成的比喻物件** | 拍不到的东西 | 只生成具体物件（一枚币、一座楼、一条蛇），抠出来放进前后层，同光同调色；写实的标"AI生成" |
| **开头预告本片的图** | 后面有好东西 | 0.5 秒一张，闪过本片后面会出现的几张图 |

## 手法 → 模板里怎么写（模板档）

模板档里，上面这些手法已经做进场景和接法：动作的时长、方向、前后层、模糊都调好了，镜头表里写参数就行。还是先写 `says`，意思对得上才用。参数以 `kit/scenes.js` 每个场景的 `help` 为准，例子在 `kit/README.md`。

| 手法 | 模板里怎么写 |
|---|---|
| 人抠像压巨字 | `scene:'person'`：`img`（抠像）+ `words:['5.2','万亿']` + `color` |
| 人身后换背景 | `person` 的 `from:{img:'原照片', at:'@b06:市值'}`（抠图和原照片同尺寸） |
| 巨字随话翻 | `person` 的 `flip:[{at, words}]` |
| 横推换人 | 下一镜写 `enter:'push'`（两镜都是 `person`；`'push-right'` 往右推） |
| 卡片在人旁边冒出来 | `person` 的 `cards:[{at, label, value}]`；大数旁边冒小卡：`number` 的 `sub:{label, value, at}` |
| 钉住一个东西，底下换实拍 | `montage` 的 `pin` + `items`；片名钉住：`title` 的 `items`；金句：`statement` 的 `items`（`title`、`statement` 只给一段实拍时连续放，就是"实拍退成底"）；圆盘徽章钉在角上：`footage` 的 `badge` |
| 同一个世界里换机位 | board 系列：节点的 `at`，`steps` 的 `focus:id / [ids] / 'all'`；只亮不动镜头用 `light`，出现并放宽看全用 `show` |
| 平面倒成桌面 | 下一镜写 `enter:'flat'`，接 `number`、`chart`（新主角立在倒下去的上一镜上；图表会从桌面上立起来）。能接 flat 的只有 `number` `chart` `equation` `change` `stats` 和不带 `items` 的 `title` `statement` |
| 甩出 / 推进来 | 画框：`frames` 的 `items[].at`（念到一样甩进来一样）；整镜：`enter:'whip'` / `'whip-left'` |
| 上一镜虚化当底 | `enter:'blur'` |
| 镜头沿着差距走 | `bars` 的 `gap:{at, a, b, text}`；排行榜从末尾走到第一名：`ranking` 的 `climb` |
| 推过镜头 | `enter:'through'`（`throughAt:[x,y]` 对准要冲进去的那个东西，`throughScale` 放大倍数，默认 1.6） |
| 画框推满屏 | `frames` 的 `fill:{i, at}` + 下一镜同一份素材的 `footage`，写 `settle:true` |
| 证据小卡、反应窗 | board 系列 `steps` 里写 `pop:{img 或 clip, from:节点或连线id, back:'@…'}`；不在 board 里：`scene:'popup'`，上一镜冻住压暗，窗口撑开（`kit/demo/film.js` 第 19 镜接在新闻桌面后面，从"追着问"开始） |
| 累加滚数 | `number` 的 `roll:{from, at, stop}`；board 里 `num` 节点 + `roll:{id, from, until}` 步骤；`chart` 的 `total:{label, from, to}`（跟着线滚）。一条片最多两处 |
| 慢推（实拍） | `footage` 的 `push:[1,1.06]` + `focus:[x,y]`（往哪一点推） |
| 原地换状态 | board 系列 `steps`：`nest:[里,外]`（收购）、`gray`（出局）、`mark:{id:'ok'}` / `{id:'no'}`（成不成立）、`link`（线画出来）、`flow`（钱在走）、`loop`（转了一圈）、`tag`（价签换数） |
| 原文：整页 → 那一句 → 刷黄 | `article` 的 `img` + `hl`（截不到用 `mock` + `mark`）；`zoom` 是镜头开始推向那一句的时刻，`hlAt` 是荧光笔刷过的时刻（默认 `zoom` 后 0.6 秒） |
| 沿着桌面滑过去 | `desk` 的 `items[].at`，`all` 抬高看全部；念到证据时桌面抬平、推近刷黄：`read:{i, at}` + 那一张的 `hl`（`kit/demo/film.js` 第 18 镜） |
| 关键词快闪 | `scene:'flash'` |
| 标题墙 → 一句 | `headlines` 的 `pick` + `mark` |
| 按真实比例的反差 | `versus`（圆盘面积按 `tag.value`） |
| 地图上飞过去 | `map` 节点的 `at`，或者 `steps` 的 `focus`：隔得远自动先拉远再推近 |
| 前后层、景深、运动模糊、慢漂 | 模板自动做。board 系列可调 `drift`（慢漂，默认 0.018）、`dof:false`（关掉景深） |
| 先看一个往里推、先看整体往外拉（开场） | board 系列自动（要改写 `intro:'push'` / `'pull'` / `'none'`） |
| 东西拿在手上、真火烟粒子叠层、生成的比喻物件、开头预告本片的图、底下换成实拍（图表缩到一边，身后换实拍） | 没有模板：`scene:'custom'` 手写，照上面的手法清单和下面的手法库 |

## 手法库（`scripts/moves.js`）

复用是为了质量稳定：这些动作在第六版里磨过、逐帧查过，用它们就不会再摔同样的跤（横推的前几帧露出采访者、模糊加太多糊成一片）。复用不是为了凑出一条片。

怎么选：
1. 先想这一镜要说什么（导演表里"观众多懂了什么"那一格），再来下面这张表找"说的是"对得上的那一行。
2. 选最适配的，不是选能用的。对得上才用，并且在调用里写 `why`：这一下在说什么。
3. 只是"差不多"、或者要大改参数才塞得进去，就手写。手写的镜头和用库的一样算数：第六版 14 镜里 4 镜全手写（快闪、算力、柱状图、押注），其余也是手写画面里插一两个手法。
4. 库只管动作的时间、方向、前后层、模糊。画面里的人、字、颜色、位置都由这条片自己传，不要照着第六版填。

| 函数 | 说的是 | 不适配的时候 |
|---|---|---|
| `pushSwap` 横推换人 | 换一个人、换一件并列的事来说 | 下一镜不是另一个人或并列的事（比如接图表）；上一镜也是横推进来的 |
| `bgSwap` 人身后换背景 | 话题换到另一个世界，人还是那个人 | 没有一段无切点、人在动的实拍可抠；人在原片里太小或被挡住 |
| `megaFlip` 巨字随话翻 | 同一个人，换一个说法 | 新旧两句不是同一件事的两面；人已经换了（那是 pushSwap） |
| `cardFocus` 卡片在人旁边冒出来 | 他说到的这样东西，和身后的大字一比 | 小卡和大字之间没有可比的关系；卡上要放一大段字 |
| `frameFill` 画框推满屏 | 推近这份东西，接着讲它背后的人或事 | 下一镜不是画框里的同一份东西，只是想换个画面 |
| `whipIn` 甩进来 | 又来了一样东西，几样要同时停在屏上 | 东西本来就在世界里（让镜头去找它）；一个个排队甩进来 |
| `layFlat` + `standUp` 倒成桌面、新主角立起来 | 前面的讲完了退成底，新东西站在它上面 | 前面的东西后面用不上了（直接切，或者推过镜头） |
| `montage` 钉住一个东西、底下换实拍 | 这件事 = 这些画面 | 前景没有钉住的视线落点；底下的实拍要观众看清 |
| `popWindow` 证据小卡、反应窗 | 从这里拎出一份证据或一句原声，看完回来 | 证据要细读很久（给全屏）；背景那张图之后不再用 |
| `blurToBase` 上一镜虚化当底 | 两个世界之间，没有能带过去的东西 | 有能带过去的数、人、画框：带过去更好 |
| `pushThrough` 推过镜头 | 冲进下一个世界，冲进去的是那个东西 | 同上；放大中心对不准要冲进去的那个东西 |
| `roll` 累加滚数 | 累加、越来越多本身就是意思 | 这句话没有累加（"估值八千五百二十亿"）；这条片已经滚过两次 |

工具不算手法，不用写 why：`S25.camPath` 和 `camKeys`（一镜的机位、同一个世界里换机位）、`desk3d`（3D 桌面）、`L`（分层）、`cutP`（抠像跟人）、`mega`、`brow`、`demote`。

人站在巨字前面、镜头沿着差距走、真火烟粒子、生成的比喻物件、东西拿在手上：画面太依赖这条片的内容，没有封装，照上面的手法清单手写。

## 代码手感

- **2.5D 相机**：机位 `{x,y,s}` 是焦平面（z=1）上画面中心对着的点和放大倍数。深度 z 的层：`scale = 1 + (s-1)·z`，平移 `-(x-960)·z`。远的层 z<1，所以动得少。
- 一镜的机位 = 起点 + 几次移动（每次 d 秒，ease-in-out）+ 两次移动之间慢推。`camPath` 的 drift 填 0.016–0.025：第六版这样填，量出来慢漂 3.0%/秒，落在参考片的 2.8–3.6 里。同一个 t 永远算出同一个机位（逐帧渲染是确定的）。
- **运动模糊**：用上一帧（t−1/30）的机位算这一层在屏幕上挪了多少像素，按这个量挑一档方向模糊；推拉太快时再加一点整体虚。
- **景深**：离镜头对着的点越远越虚（最多约 5px）；不讲的东西亮度降到 0.4、饱和降一半。
- **抠像跟人走**：`matte.py` 会写出每帧头肩的中心 `box.json:cx`。放人时按这一帧的中心对齐，人在原片里走动，画面里他就钉在你要的位置（等于摄影师在跟拍）。
- 这些都封装在 `scripts/stage25d.js` 里（只是工具函数，不是镜头）。
