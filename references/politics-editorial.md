# 时政的写法：立场、风格、情绪、反驳

这份管"怎么说"。事实和来源怎么记，见 `politics-rules.md` 和 `editorial.json`。

## 一、立场（stance）

立场是**判断重点**，不是事实开关。

| 立场 | 它让你更看重 | 它不改变 |
|---|---|---|
| `neutral` | 证据权重、程序是否正当、各方的约束条件 | 事件时间、票数、原话、身份 |
| `green-leaning`（台湾） | 主权与安全、民主程序、公民社会空间 | 同上 |
| `blue-leaning`（台湾） | 两岸稳定与经贸、行政效率、法理边界 | 同上 |
| `establishment-leaning`（香港） | 制度连续性、治理效能、国家安全框架 | 同上 |
| `pan-democratic-leaning`（香港） | 程序公义、公民权利、问责与透明度 | 同上 |
| `custom` + `stance_note` | 用户自己写的判断重点 | 同上 |

**四条不能破的线**

1. **反证不删**：对方最强的论据要摆出来再反驳；删掉决定性反证得到的结论是伪造。
2. **不代言整个阵营**：一个人、一个派系的人说的，不能写成"蓝营认为""泛民认为"。
3. **不把官方声明当已证实**：官方声明只能证明"官方这样说"，不能证明其内容为真。
4. **neutral 也可以有结论**："一方证据明显更弱"是合法结论，强行五五开是另一种歪曲。

**同一件事，三种写法的差别**（以"某市公布交通方案、未列费率与起始日；财政部门把该设施维护支出列在同一收费收入项下"为例）

注意三点：**事实只到这里**（文件没写费率、预算科目这样列）；"这意味着什么"是判断；判断要留条件。

- `neutral / objective`：文件提到收费 4 次、没给费率与起始日；预算把维护支出列在通行费收入项下。**判断（条件式）**：如果下一期政策简报仍不公布测算，可以合理怀疑收费已经在准备；但在看到测算或正式提案之前，"要收费"仍然只是推断，不是事实。观察点：下一次简报。
- `green-leaning / adversarial`：先摆市府"程序安排"的原话，再指出文件不写费率、预算科目却已就位的**不一致**，追问"为什么不公开测算"。**落点要落在追问和程序要求上**（要求公开测算），不要凭空断定动机（"为了绕过监督"需要证据：比如法规里确实有免议会程序的口子）。
- `blue-leaning / traffic`：从"四次提收费、零个数字"这个细节切入，交代谁在问、市府怎么答，把悬念留在"什么时候公布测算"。**悬念的兑现物是一个可验证的东西**，不是暗示有人在暗箱操作。

三种写法的**事实、日期、数字完全一样**，差别在看重什么、先说哪一句、判断留多少条件。

**反证不足时的正确姿势**：财务科目只能说明"这笔钱打算从收费里出"，不能单独证明"决策黑箱"。要下更重的判断，就得再补证据（法规条文、会议记录、当事人的说法）；补不到，就把话说回条件式。

## 二、风格（styles）

可以组合，第一项为主风格。`["traffic","outrage"]` = 悬念开场 + 愤慨推进。

### objective

- 开头：事实里最反常的那一点，不加评论。
- 正文：证据 → 解释 → 条件式判断（"如果 A，则 B"）。
- 结尾：一句判断 + 一个可验证的观察点。
- 避免：伪中立（明明证据一边倒却假装平衡）、把推测写成结论。

### traffic（爆料悬念）

**合规的内幕感，全部来自公开细节**：

- 同一份文件里前后不一致的表述；
- 时间线上的空档（"发布会开了，时间表没给"）；
- 说辞和账面/记录对不上；
- 某个关键数字被反复改口。

写法：开头摆出这个反常细节 → 每段给一个新信息 → 结尾兑现（不能吊完胃口就没了）。

**红线**：

- 不说"我刚收到内部消息""独家确认某人收钱"——除非真有可署名的来源。
- 疑问句不能洗白暗示。写"这是不是有人故意不写？"和写"有人故意不写"在观众那里是一回事。
- 片尾免责声明不能抵消前面的强行暗示。

**合规说法**："这份公开记录里有一个容易忽略的细节""支持者为什么急了""方案里出现四次、零个数字"。

### outrage（愤慨）

- 开头直接点出最不能接受的那件事。
- 递进反问、短句、断句；数字和原话砸在关键处。
- 批评落在**政策、公共人物的言行、论据、责任**上。
- 避免：每句都骂（强度会疲劳）、把强度写成对某个群体的敌意、编造对方的原话。

**粗口**由 `profanity` 单独控制，默认 `none`：

| 档位 | 用法 |
|---|---|
| `none` | 完全不出现。愤慨靠句式和节奏，不靠脏字 |
| `mild` | 一条片 1–2 处，落在最该重的那一句；每处都要有替代词 |
| `bleeped` | 同上，但配音消音、字幕打码 |

每处粗口都在文案里标出消音替代词，方便出 `bleeped` 版本。

### adversarial（强对立）

- 开头**先把对方的论点说准**（说歪了自己就输了）。
- 正文逐条：对方论点 → 他的依据 → 依据的问题 → 替代解释。
- 结尾给对方留一个"他若成立需要什么"的条件。
- 避免：稻草人、把对方写成没人会信的蠢话、人身攻击代替论据。

## 三、情绪曲线（emotion 0–3）

| 段 | 0 | 1 | 2 | 3 |
|---|---|---|---|---|
| 开头 0–5 秒 | 平述最反常识的事实 | 一句钩子 | 直接点最不能接受的事 | 短句连打，一句一断 |
| 证据段 | 完整念出，留足阅读时间 | 同上 | 略快，但证据仍要能读完 | 快，证据只留关键句 |
| 关键矛盾 | 陈述 | 加重 | 反问 | 递进反问 2–3 句 |
| 反驳落点 | 条件式 | 明确判断 | 强判断 | 压倒式，但不编事实 |
| 结尾 | 观察点 | 判断 + 观察点 | 判断 + 一句留白 | 判断，短，停 |

**证据阅读区不叠惊慌字幕**；音效和音乐给人声让路（`mix.py` 已经让配乐避让人声）。

## 四、导演表在时政里的额外两列

在上面游的导演表基础上加：

| 列 | 写什么 |
|---|---|
| `claimIds` | 这一镜讲的是 `editorial.json` 里的哪几条 claim |
| 角标 | 这一段挂哪个来源、什么性质（事实/原话/分析/未证实） |

**一条镜只能说清一件事**：一镜里既放委员会发言又放市民报告，角标就没法只挂一个。

## 五、标题和封面

- 标题给"具体的东西"，不给立场形容词：`四次提收费，零个数字` 好过 `政府又在骗人`。
- 有 `traffic` 风格时，标题可以是那个反常细节本身。
- 未证实的东西**不能进标题**（标题会被单独截传播）。
- 虚构片标题旁必须有"虚构演绎"。

## 六、未证实（unverified）

只在一种情况下用：**有具名的媒体或当事人提出了这个说法**，你要报道"有人这么说了"。

写法三步：

1. 谁、哪天、在哪说的（`attribution`）；
2. 他说了什么（原话或转述）；
3. 证据是什么、争议在哪（没有证据就直说没有）。

画面和口播**都要出现"未证实"**（`marked_on_screen:true`）。不能升级成"我们确认"。

## 七、虚构（fiction）

- `content_mode:'fiction'`，`fiction_marker` 写标记文字，全片右上角常驻。
- 用虚构政体、虚构人物、虚构机构；**不给真实官员或真实机构安虚构的罪名**。
- 标题、封面、片头引导语都要和标记一致，不能只在片尾放一行小字。
- `claims` 里每条 `kind:'fiction'`，能追到合成来源就写上（`source_type:'synthetic'`）。

## 八、港台政论四幕式文案架构与节奏规范（彻底摆脱通稿腔）

政论短视频的核心不是平铺直叙的“中学生议论文”，而是**悬念、博弈、抓包、打脸与追责**。写文案与分镜必须严格遵循四幕式结构：

### 1. 四幕式戏剧冲突架构

| 幕 | 时长 | 核心任务 | 标点与语气 | 画面配合 |
|---|---|---|---|---|
| **第一幕：爆点突袭（Hook）** | 0–5 秒 | 用最荒谬的数字反差或名嘴式惊呼破题，**绝不平述**。 | 短句、破折号拉长悬念、感叹号！“這不是鬼扯是什麼？！”、“八千萬公帑，說蒸發就蒸發？！” | `pol-hero`（大头大字砸入 + 相机快速慢推） |
| **第二幕：现场抓包（Evidence）** | 5–20 秒 | 铺垫句引出真实原声/公文原件，让当事人自己说出破绽。 | “你看他在台上怎麼講的——”（破折号后进原声），不抢原声风头。 | `footage`（原声原片推入）或 `pol-evidence`（公文高光） |
| **第三幕：光速打脸（Flop）** | 20–45 秒 | **政论最高潮**：将“当年的宏愿”与“如今的现实”对撞。 | 设问讽刺：“聽起來義正辭嚴對不對？好，那我們來對賬！”、“回力鏢光速打到自己臉上！” | `pol-slap`（左右昨非今是对比 + 砸下【自打臉】红印章） |
| **第四幕：灵魂追责（Verdict）** | 45–60+ 秒 | 连环排比追问，利益归因（谁分钱、谁倒霉、谁担责）。 | 短句连珠炮：“錢呢？進了誰的口袋？責任呢？誰來扛？！老百姓等了一年，換來一句謝謝指教？！” | `pol-hero` 或 `pol-interrogate`（连续推进追问） |

### 2. 镜头密度硬指标（解决画面单调与缺少分镜）

- **单镜头时长严格控制在 2.0 ~ 3.5 秒**：严禁出现超过 4.5 秒的静态镜头！一段 60 秒的视频，分镜数必须达到 18 ~ 25 镜。
- **全片无静止死帧（Continuous Motion）**：每一镜都必须调用动态相机推进（`autoPushCam`）或原片推拉（`push: [1.0, 1.12]`）。
- **动静交替**：爆点砸入（Slam + Shake） $	o$ 原声真实沉淀 $	o$ 打脸印章盖戳（Stamp） $	o$ 镜头冲锋。

### 3. 配音与语气参数（TTS 调优）

- **语速（rate）**：政论必须有紧迫感，速度建议在 `+0%` 至 `+5%`（**严禁使用 -4% 的低沉慢速**，会导致极度干瘪枯燥）。
- **停顿控制（gap）**：单句之间 gap 设为 0.15 ~ 0.22 秒，不留拖泥带水的空白；在打脸和抛出反转前，用破折号 `——` 制造戏剧停顿。
