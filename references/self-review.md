# 自己审一遍：交片前的复核卡

这份是给**执行模型**用的，不是给用户的检查表。你可能没有人在旁边看片，那就得自己按顺序过一遍，并把结论写下来。

程序能查的（踩点检查）在 `scripts/preflight.mjs`；这份管**它查不了的那一半**：语义与图像。

## 什么时候看、看什么

| 站点 | 什么时候 | 看什么 | 看完写什么 |
|---|---|---|---|
| A 配音前 | 文案定稿、还没跑 temp_voice | **事实与引语**：这段是我的判断还是引用？引用的话是谁说的？数字有没有被放大？ | `review.json` 里 `stage:"script"` |
| B 渲整片前 | `--check` 通过、`--sheet` 出来 | **画面**：字压到脸没有、抠像残片、台标、空场、重复版式 | `review.json` 里 `stage:"visual"` |
| C 交片前 | `preflight --stage delivery` 跑完 | **承诺**：封面/标题答应的事，片子有没有做到 | `review.json` 里 `stage:"delivery"` |

**不用等谁来批准。** 你自己看过、写了证据，就算完成；除非是"我看不了图"这种能力缺口——那要如实写出来。

## A 稿子：六个必答

对**每一条** `kind:"quote"` 的 claim：

1. **说话人是谁？** 逐字对来源。`speaker` 写的是不是原文里那个发言人。
2. **这是原话还是转述？** `quote_mode` 必须是 `verbatim` 或 `paraphrase`。
   - 转述标成 `verbatim` 是最常见的错误，也最伤：观众以为那是他说的。
   - `verbatim` 必须有 `excerpt`（原文摘录），能逐字比对。
3. **有没有把一个人的话，写成一群人的？** "民进党认为"和"沈伯洋说"不是一回事。
4. **数字有没有扩大？** 7% 不能写成"全部缺席"；"有些没出席"不能写成"一次都没到"。
5. **因果/动机有没有越界？** "账上挂了这笔支出" ≠ "他打算偷偷收费"。判断要标 `kind:"analysis"` 并写 `reasoning`。
6. **对方的反驳有没有被删？** 只说一边的论据，就是另一种编造。

**写法**：在 `out/review.json` 里逐条记，不要只写 `"pass": true`。

```json
{
  "stage": "script",
  "input_hash": "<preflight 报告里的那个哈希>",
  "items": [
    {"claim": "c2", "checked": "逐字对 ETtoday 逐字稿第 20 条", "result": "paraphrase 正确，原文含'即刻召集各局處…由我親自主持'"},
    {"claim": "c5", "checked": "对方最强论据（蒋确实主持了三个会报）有没有写进去", "result": "写进去了，第 6 镜"}
  ]
}
```

## B 画面：这几样程序看不出来

打开 `out/sheet.png`（或 `preflight --save-frames` 的帧），逐镜问：

- **字压到脸了吗？** 压一点是风格（参考图里互相压），把眼睛遮住就不是了。
- **抠像有残片吗？** 透明 PNG 边缘常留下原图的贴纸、文字、桌面纸片。
- **台标裁干净了吗？** 原素材的角标、下栏、竖栏。**模糊不算去掉**——模糊后 logo 还在。
- **有没有空场？** 一镜十几秒只有标题、行都堆到后面，观众看到的是"卡住"。
- **版式重复吗？** 连着三镜同一张清单，等于只做了一个镜头。
- **动效是不是只有装饰？** 震一下、爆一下，要落在"说到那个词"上。

## C 交片：承诺兑现

- **封面答应的事，片子做到了吗？** 封面写"谁在管这座城市"，片子里要有答案。
- **标题有没有说不该说的？** 未证实的东西不能进标题；标题会被单独截图传播。
- **字幕文件真的对得上配音吗？** 时间、断句、有没有把"跨局處會議"切成"跨局處會/議"。

## 三条硬边界

1. **不改用户选的立场/情绪。** 修事实不等于把文案改中立。用户要偏绿愤慨，就保持偏绿愤慨——把错的引语修对，不要顺手把语气也削平。
2. **不为了过检查偷偷加角标。** `overlays:'none'` 就是不要角标；把来源塞回画面只会让片子违背用户要求。
3. **不谎称验过什么。** 看不了图就说看不了；没有 ASR 就说没有母语听感认证。**"程序 0 错误"不等于"语义正确"**。

## 什么时候停

- **同一类错误改了三轮还在**：停下来，把证据、试过的修法、缺什么资源写出来。不要继续整片重渲。
- **没有新证据**：不重复渲。改了文案才重配音；改了镜头才重出片；只改字幕就只重导字幕。

## 落了什么

```
out/review.json       你写的复核记录（带 input_hash，声明"我是对这一版看的"）
out/preflight.json    程序写的检查结果（blocking / warnings / review_required / evidence）
out/sheet.png         每镜三帧
```

`preflight --stage delivery` 会核对 `review.json` 的 `input_hash` 和当前输入一致——不一致就说明"你看的是旧版"，要重看。
