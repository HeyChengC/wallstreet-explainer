# 本地自媒体风格：封面、字幕、动效、无角标

这份写港台本地自媒体的**画面规格**，以及和上游财经风格的区别。

## 二、封面（必需输出）

`cover_1280.jpg` + `cover_1920.png`，**不是**把影片第一帧当封面。

规格（按 1920×1080 设计，自动缩到 1280×720）：

| 项 | 值 |
|---|---|
| 人物 | 1–3 位，头脸高度约 **380–560px**（在 1080 坐标系里即 570–840），肩膀留少量，至少一个前景大头 |
| 抠像 | **透明 PNG**，不是矩形头像贴片；白/黄描边 + 黑投影 |
| 主文案 | 2–3 行，每行 **4–8 个中文字**；最关键一行 **105–155px**（1080 系即 158–232px）Heavy |
| 填色 | 白 / 亮黄 / 红，**8–14px 黑描边 + 硬偏移阴影**；可倾斜、可锯齿 |
| 背景 | 与题材相关的实拍局部、红黄渐变、漫画爆裂、放射线；**不是深蓝布纹** |
| 禁止 | 小英文、片名眉题、来源角标、研究或虚构标记、任何角落小字 |

**TW**：红黄白 + 深蓝；头像与字对撞；一个爆裂短词。
**HK**：橙/黄/黑 + 白字；粤语问句可两色交替。

**自查**：缩到 320×180 还能一眼读懂主体和标题。

## 三、字幕（第一眼就看到的那个）

上游默认是 MiSans Medium 500 / 60px / 柔阴影——**那是财经片**。本地版：

| 项 | 值 |
|---|---|
| 字体 | 地区字体栈，**900 字重**（Noto Sans TC/HK Black） |
| 字号 | **72–88px** |
| 描边 | 6–10px 黑描边，**必须 `paint-order:stroke fill`**（否则描边吃掉字身，看起来像"细骨架裹黑边"） |
| 阴影 | 硬阴影 `4px 4px 0 #000` |
| 颜色 | 白字；关键词可刷黄 |
| 每块 | **8–15 字**，最多两行；无标点长句也要按字数硬切 |
| 位置 | 底部安全区，不能一行 30 字铺满 |

## 四、正文花字

| 项 | 值 |
|---|---|
| 主体 | 100–165px |
| 落点短语 | 180–245px |
| 字重 | 900 |
| 描边 | 8–14px，`paint-order` 同上 |

一般文字和花字**不能同时争四个主角**：一个正文焦点 + 一块字幕即可。

## 五、动效（故意俗，但技术不能坏）

`visual_intensity:3` 应该一眼和干净版不同。**全部是 t 的纯函数，同一个 t 永远画同一帧。**

| 效果 | 做法 | 时长 |
|---|---|---|
| `slam` | 0.78 → 1.12 → 1.00 | 6–10 帧（0.2–0.33 秒） |
| `shake` | 8–16px 位移，衰减 | 3–5 帧 |
| `burst` | 漫画爆裂/放射线，**画在人物后面** | 弹入 0.2 秒，停到下一镜 |
| `sticker` | 惊叹号/问号/怒气符，弹进来后停住 | 0.2 秒 |
| `head-bob` | 大头轻晃 ±3° | 持续性 |

**规矩**：

- 高强度镜头通常 **1.5–3 秒**出一次新信息或明确强调；证据可 3–5 秒。
- 每段**最多一个主机制**，不要放射线 + 火焰 + 震动全上。
- 不靠快速高对比闪烁制造"廉价"；硬切、跳切、粗箭头、夸张 scale 已经够。
- **爆裂必须在人物后面**，不能盖脸。
- 字幕不跟着震。

## 六、无角标（`overlays:none`）

**用户明确要求：封面和影片都不显示任何角标。**

关掉的东西：

- `.pol-badge`（来源 + 性质）
- `.pol-fic`（虚构演绎）
- `.pol-jtag`（判断的性质小 chip）
- 角落年份、主题小字（`kicker`）——**新加的角落小字同样是角标**
- 台标、节目名、logo、水印（原素材自带的也要裁掉）

**怎么关**：

```js
K.politics.display('no-badges');   // 帧层角标全关
// 场景里不要写 kicker（写了也不画）
```

`--check` 会打印 `虚构标记：已关闭（display:'no-badges'，私人研究预览；出处与真实性类型在 editorial.json 里）`。

**关了不等于没有记录**：`editorial.json` 里的 `sources` / `claims` 仍然要写全，事实/分析的区分仍在文件里。**画面不显示 ≠ 事实不分**。

**原素材自带的台标要裁掉**：挑干净官方素材，或在抽帧时放大裁切（`footage.py extract` 的 `zoom`/`ax`/`ay`，或直接用 `PIL` 裁到人脸范围）。不能只模糊就说"去掉了"。

## 七、两种风格的差别

| | 上游财经 | 本版本地 |
|---|---|---|
| 主角 | 抽象论证、图表、数字 | **人脸** |
| 底 | 深蓝斜纹织物 | 红黄撞色 / 实拍 / 爆裂 |
| 字 | 细边卡片、小标题 | 粗描边巨字、贴纸 |
| 动 | 克制 2.5D、慢推 | slam、震动、硬切 |
| 字幕 | 60px 500 柔阴影 | 80px 900 黑描边 |
| 角标 | 有（来源/性质） | **无**（出处放外部 ledger） |

## 八、技术约束（不能因为"要俗"就破坏）

- `seek(t)` 必须确定：同一 t 永远同一帧，不用 CSS 动画、不用播放时钟。
- 图片、字体必须在片子目录里（`render.mjs` 的服务器根就是片子目录，`../` 会 404）。
- 抠像 PNG 建议预缩到 1920 尺度再用，几十 MB 的原图逐帧解码很慢。
- 字幕 `top` 与花字 `y` 不重叠：花字全区在 900 以上。
