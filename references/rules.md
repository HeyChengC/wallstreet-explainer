# 硬规则

做片子必须守的规则。每条有编号、能检查。弱一些的模型可能看不了图，就靠这份和 `render.mjs --check` 的文字把关。手写档也守（除了专讲模板参数的那几处）。

最后一栏是怎么查：

- **自动**：`node scripts/render.mjs --dir <片子> --check` 会查。写错的直接报错（必须改），其余在"要看一眼"里提醒。
- **部分**：`--check` 只查一部分，剩下的自己查。
- **手查**：对着镜头表（`film.js`）、`script.json`、`out/sheet.png` 自己查。

提醒不是禁令：每一条都答得上"为什么这里就该这样"，就可以留着。规则为什么这么定，看每组后面的出处。

`--check` 会自动查（全部或一部分）的：第 1、3、7–13、15、17、18、20–28、30–32、41 条，还有最后"配额"表里的金句、章节卡数量。

## 一、每一镜说什么

| # | 规则 | 怎么查 | 查法 |
|---|---|---|---|
| 1 | 每一镜写 `says`：一句话，说这一镜让观众多懂了什么 | 读出来是"观众懂了：……"，不是"画面上有……"。说不出来，就是这一镜还没想清楚 | 自动（没写会提醒） |
| 2 | 先有 `says`，再按"这句话在说什么"选场景（本文最后的决策表）。不按顺序套，不为了换花样选 | 每镜的场景都能在决策表里找到对得上的那一行；只是"差不多"就换一个，或者 `custom` | 手查 |
| 3 | 一镜一个主角：正在讲的那个亮着，其余压暗、变灰 | 用一句话说出这一镜的主角（一个人、一个数、一张原文）。说出两个，就拆镜，或者用 `focus`/`light` 一次只亮一个 | 部分（巨字超过两组，画框、卡片、对比行、截图的张数超了会提醒） |
| 4 | 每一镜接住上一镜的一样东西（同一个数、人、画框、原文）；接不住，要说得出为什么切 | 导演表的"承接"一列每镜都有 | 手查 |
| 5 | 东西朴素出现，镜头去找：用节点的 `at`、`steps` 把"出现、亮起"挂在念到的字上，不另加入场动画 | `custom` 里没有弹出、回弹、打字机、扫光、整体重排、带模糊砸进来 | 手查（模板自己就是这么动的） |
| 6 | 图形只演钱和关系：多少钱、谁和谁、谁大谁小、钱怎么流。"是谁、在哪、什么产品"用真素材说 | 每个图形镜（数、圆盘、柱子、图表）说得出它演的是哪笔钱、哪个关系 | 手查 |

出处：`thinking.md` 第 1、2、5 节；`motion.md` 五条原理的 1、2、5；`lessons.md` 的"模板档"。

## 决策表：这句话在说什么 → 用哪个场景

先写 `says`，再在这里找意思对得上的那一行。"别用"那一栏对上了，就换括号里的场景。33 个场景都在这里；参数和例子在 `kit/README.md`。

**数和钱**

| 这句话在说什么 | 用 | 什么时候别用（换成） |
|---|---|---|
| 一个决定性的数（金额、估值、市值），这句话的落点就是它 | `number` | 一句里要比两三个数（`bars` / `stats`）；数后面马上要拆构成（`network` / `board`） |
| 一笔账：几个数一算得出结果（摊到每天、几家相加） | `equation` | 超过 5 项（拆成两步）；结果不是这句话的落点（`number`） |
| 同一个数从多少变成多少（涨了几倍、跌了九成） | `change` | 中间还有好几个阶段（`chart` / `timeline`）；两个数不是同一样东西（`bars` / `versus`） |
| 两到四个数排开认一认（营收、利润、市值） | `stats` | 要比大小（`bars`）；只有一个数（`number`） |
| 两三个数比高低，"差一大截" | `bars` | 超过 5 根（`ranking`）；差距小到看不出来（别比） |
| 两样本该相配的东西差得离谱（估值 vs 收入） | `versus` | 差别不大（别比）；要读出具体差多少（`bars`） |
| 一串数按年变化、按年累计 | `chart` | 只有一个数（`number`）；两三个数比大小（`bars`） |
| 整体里的一部分（占比、份额） | `share` | 超过 5 块（合成"其他"）；比几个整体的大小（`versus`） |
| 五家以上排个队 | `ranking` | 只有两三家（`bars` / `versus`） |
| 甲 vs 乙逐项比（两到四项） | `compare` | 超过 4 行（挑最要紧的）；只比一项（`versus` / `bars`） |

**关系和结构**

| 这句话在说什么 | 用 | 什么时候别用（换成） |
|---|---|---|
| 几家公司 / 几个人并列；谁收购谁（嵌套）、谁出局（变灰） | `discs` | 它们之间有流向（`network`）；只有一家（`number` / `footage`） |
| 钱 / 关系怎么流：谁投了谁、钱转了一圈 | `network` | 没有方向的并列（`discs`） |
| 一件事分几步、几个条件成不成立 | `flow` | 只是并列几样（`discs`）；按时间先后（`timeline`） |
| 三到六件事按时间排 | `timeline` | 只有两个时间点（`change` / `bars`） |
| 国家、城市之间的事（在哪设计、在哪造、钱流向哪） | `map` | 要精确国界（`board` + 标准地图底图放进 `under`）；只是"这家公司在美国"（一句话带过） |
| 一群里拎出一个（"各国都在砸钱，最大的是美国"） | `cards3d` | 只有两三样（`discs`）；不用拎主角（`discs` 一排） |
| 几样东西要放在一个世界里讲，上面几个都对不上 | `board` | 只有一个数（`number`）；要看清一段实拍（`footage`） |

**人**

| 这句话在说什么 | 用 | 什么时候别用（换成） |
|---|---|---|
| 这个人 = 这个数 / 这个身份（第一次把人和数绑在一起） | `person` | 没有他的抠像（`profile` 用 `photo`，或 `discs` 的照片圆盘）；巨字超过两组、每组超过 4 个字 |
| 关键人物第一次出场：是谁、什么身份、两三件事 | `profile` | 只出现一次、不重要（一句话带过）；已经出场过（`discs` 的照片圆盘或 `person`） |
| 当事人的一句原话，没有能用的原声画面 | `quote` | 有原声画面（`footage` 放原声，前一句做铺垫）；话超过 30 字 |

**真画面和证据**

| 这句话在说什么 | 用 | 什么时候别用（换成） |
|---|---|---|
| 说到的东西有真画面：人、地方、产品、发布会 | `footage` | 认不出是谁、是什么（换一段有脸、logo、标题的）；想在上面加字（`person` / `montage`） |
| 这件事 = 这些画面（前景钉一个数或标题） | `montage` | 前景没有视线落点；底下的实拍要看清（`footage`） |
| 两三样有画面的东西并列（芯片和数据中心） | `frames` | 只有一样（`footage`）；超过 3 样 |
| 观众可能不信的数：给原文出处 | `article` | 原文要读很久（压成一句再刷）；没核实过的数（别放）；好几篇要一起看（`desk`） |
| 几家各自的新闻（截图标题里有公司名和金额） | `desk` | 截图的字太小、认不出是哪家（换截图，或 `discs`）；只有一篇（`article`） |
| 从上一镜拎出一份证据 / 一句原声，看完回来 | `popup` | 在 board 系列里（用 `pop` 步骤，舞台不冻住）；证据要细读（`article` / `footage`）；第一镜 |
| 说法很多，最要紧的只有一句 | `headlines` | 编不出真的标题；只有两三条（`desk` 放真截图） |
| 一个 App / 网站 / AI 产品的界面 | `device` | 截图上没有要看的东西（`footage` 放录屏）；有官方产品实拍（`footage`） |

**结构和包装**

| 这句话在说什么 | 用 | 什么时候别用（换成） |
|---|---|---|
| 片名 / 章节：这条片（这一段）要回答什么问题 | `title` | 片名前空等（第一句说完就进）；章节卡超过 3 张 |
| 长片的目录、现在讲到第几章 | `agenda` | 一两分钟的短片（不用目录） |
| 一句判断压成金句：结尾，或者一大段讲完收一句 | `statement` | 放一段话（只放一两行）；一条片超过 3 次 |
| 开头钩子：全网都在说一个词 | `flash` | 话题不热、编不出真的出处；关键词超过 4 个字；不是开头 |
| 上面都对不上 | `custom` | 只是想换个花样（先找最对得上的那个） |
