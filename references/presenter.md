# 真人口播：人怎么融进来

2026-11-02 从四条小Lin说（2026 年的长片：关税、最大现金收购、AI 资本混战、日元）拆出来，再在《打仗黄金反而跌》里做成模板。拆片笔记、连续帧和量化数据留在作者本地（参考片画面里有原作者本人）。

## 一句话

**她是这条片的"地面"。观众每离开她一会儿就回到她身边；证据和图形不是盖掉她，而是挂进她的房间、或者把她带进图形的世界。** 原来的 wallstreet-explainer 没有主持人，所以拿当事人抠像去演"人站在巨字前面、人身后换背景"——这些动作本来就是小Lin本人的。现在把它们还给主持人；当事人回到实拍、圆盘和原文里。

## 量出来的数（四条参考片）

| | 区间 |
|---|---|
| 她在画面里的时间（全屏 + 圆窗 + 竖窗） | 67–75% |
| 其中全屏在房间里 | 31–60% |
| 完全没有她 | 25–33%，**每段只有 2.5–4.5 秒**（中位） |
| 全屏一段多长 | 中位 4–6 秒，75 分位 7–10 秒 |
| 全屏时景别跳一次 | 每 6–8 秒（同一个机位裁出远、中、近三档，跳在句子转折处） |
| 声音 | 平均约 -20 dBFS（我们按 -14 LUFS 出片，比例照这个：配乐压得很低，人声为主），没有彻底静音 |

短片（30 秒左右）比长片密：她全屏的那几段 2–4 秒就要有一个新落点（景别跳、墙上挂东西、换世界），没有她的那段 1.5–2.5 秒就回来或者变圆窗。

## 七种样子（从她最重到最轻）

| 样子 | 什么时候 | 模板写法 |
|---|---|---|
| 1 房间全屏 | 开场、提问、表态、吐槽、转折、结论 | `{scene:'host'}`，`zoom` 写景别跳 |
| 2 东西挂进她的房间 | 她"拿出来给你看"：一句老话里的两样东西、一个对比（黄金 vs 国债） | `host` 的 `items`：照片 / 实拍 / 价签挂在她身后的墙上，**头发和肩膀压在它们前面**（用她的逐帧抠像） |
| 3 身后换世界 | 全片最重要的那个词（利率），一条片一两次 | `host` 的 `swap`：那一帧房间换成织物舞台，巨字夹在她和底之间，从 1.12 倍长到 1 |
| 4 和图形并排 | 一段链条、一张图板要细看，又是她在讲道理 | 任何场景加 `host:'window'`：画面缩进左边的板子，她缩进右边竖窗 |
| 5 角上圆窗 | 全屏证据：实拍、金价图、新闻原文 | 任何场景加 `host:'pip'`：左下角一个圆，跨过底下几刀不动（"她还在说"的那根线） |
| 6 完全没有她 | 极少：照片推满屏变成实拍的那一下（她被盖住，圆窗随后淡入） | 不写 `host` |
| 回到房间 | 证据讲完，她接着说 | `{scene:'host', enter:'grow'}`：从圆窗 / 竖窗长回全屏；`enter:'drop'`：图形往下掉，露出一直在后面的她 |

## 七种样子之间怎么走（每一下都是"接住"）

- **房间 → 圆窗 / 竖窗**：她从全屏缩进窗里（0.5 秒，框、圆角、裁切一起走）。框里先是上一镜的样子（墙上的东西、换了的世界），0.3 秒里淡成干净的房间。模板自动做。
- **圆窗 → 圆窗**：底下换刀，圆不动。
- **竖窗 ↔ 圆窗**：框直接变形过去（0.45 秒）。
- **圆窗 / 竖窗 → 房间**（`enter:'grow'`）：框长回全屏，框里就是下一镜真正的样子（如果下一镜一开头就换世界，长出来时框里已经是换好的世界）。
- **墙上照片 → 满屏实拍**（`items[].fill`）：镜头冲进那张照片，照片长到满屏、边框退掉、摆正、换成实拍。下一镜写同一段实拍的 `footage`（`from:0.5`）+ `host:'pip', pipIn:'fade'`。这是"乱世买黄金 → 可这次中东真在打仗"的那一下：她墙上那张"乱世"，变成了真的战火。
- **同一张照片前后呼应**：开头挂上墙的两张照片，结尾那句话原样挂回来（观众认得出是同一句话）。
- **同一个词前后呼应**：中间换世界的"利率"，结尾再换一次——同一个答案。

## 墙上挂东西：放哪、多大

- 先看原片哪里是空墙：她的头两侧、肩膀以上。《打仗黄金反而跌》那条：左上海报、右上挂钟一带（原片坐标左 x≈440、右 x≈1490，y≈300）。
- **挨着她的头发放**，让头发压住照片的一条边：这一下就是"东西在她房间里"，不是贴在画面上。离她太远就像 PPT。
- 照片 560×376 左右（画面宽的三成），白边 7px，微斜 ±1.6°，压一点暖、一点暗（她的房间是暖光），身后一块软影。
- 每次最多两样，一边一样；第三样进来前先摘掉一样（`out`）。
- 价签（`value` + `vlabel`）用来放一个对比的数（"美国 10 年国债 4.9%"），照片用来放"这是什么"（黄金、乱世）。不讲了就变灰（`gray`），不对就打叉（`no`）。

## 景别

- 口播原片只有一个机位，景别在剪辑里裁：近（1.14–1.2 倍，开场、结论那句）→ 中（1，原片）。跳是硬切，不推不拉。档位之间每秒 0.4% 慢漂，人一直在动，画面不会死。
- 跳在句子转折上（"最近黄金"、"你先看一眼"），不是随便跳。挂东西之前先跳到中景，给墙留地方。
- 原片是 720p 的话，放大到 1.2 倍以上会糊；要更近的景别，口播就得拍 1080p 或 4K。

## 她的素材要什么样

- 一整条不切的口播（中间不要换机位）：时间线就是她说话的时间，画面全部挂在她说的字上（`scripts/host_timeline.py` 逐字对齐）。
- 人在画面中间、腰部以上、手在画面里（手势就是节奏）；身后的墙要有空地（挂东西用）。
- 背景和人分得开（逐帧抠像要干净）：`scripts/matte.py` + `matte_clean.py`，846 帧 CPU 上约 16 分钟。
- 数字人 / AI 生成的口播也行，注意识别出来的字：《打仗黄金反而跌》开头那句识别成"最近大黄可得劲了"，字幕按"黄金"写了，要请用户听一下她到底说的什么。

## 声音

- 人声就是口播原片的声音（`mix.py` 看到 `timeline.host` 自动整条进），配乐压在下面（`gain` -15，侧链让路），音效只点在"换"的地方：
  - 缩进窗、长回全屏、推满屏：软风声（`whoosh_soft`，峰值 -17 到 -21）；
  - 换世界：往上扬的风声 + 一声低沉的撞击（`whoosh_up` + `impact_low`）；
  - 决定性的大数字落定（-6.9%）：一声低沉的撞击；
  - 东西挂上墙、卡片亮起、荧光笔刷过：很轻的"嗒"（`tick_soft`，-24 到 -26）。
- 这几样用 `scripts/sfx_synth.py` 合成（在 `library/sfx/synth/`），不用下载。配乐用 `library/bgm` 或 paper-sticker-explainer 的 `explain_curiosity`（用户说过不错的那首，Mixkit 授权）。
- 我听不到：混完用 `mix.py --check` 量，交片时请用户听人声和配乐的比例。

## 判断用这几句

1. 这一句是她在讲道理，还是证据在说话？她讲道理 → 房间（全屏或挂东西）；证据 → 圆窗 / 竖窗。
2. 离开她多久了？超过 3 秒（短片）/ 4.5 秒（长片），就回来或者变圆窗（`--check` 会提醒）。
3. 这一下换样子，接住的是什么？她自己（缩进、长出）、墙上那张照片（推满屏）、那个词（换世界）。说不出来就别换。
4. 换世界是不是全片最重要的那个词？不是就别用。
