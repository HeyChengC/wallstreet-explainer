# 素材：找什么、怎么抓、抓不到怎么办

时政的证据和财经完全不同：公报、议会记录、记者会、原帖。这份讲清楚**各类通道的一般用法**，以及抓不到时的降级路径。

## 一、素材优先级

1. **官方记录**：政府公报、议会会议记录/表决记录、法院判决、监管机构公告
2. **记者会与议会录像**：有完整上下文的那段，不加剪辑
3. **具名新闻报道**：标题里有主体和事实的那种
4. **已核验的原帖**：当事人自己账号发的，能对上时间和身份
5. **用户提供的素材**：`source_type:'user-provided'`，记 `local_path`

**都要记 `editorial.json`**：`id` / `url` / `publisher` / `title` / `published_at`（不知道写 `null`）/ `accessed_at` / `source_type`。

## 二、部署前必须重新验证

**视频平台和新闻站点的可访问性会随部署环境、区域、时间变化。** 换一台机器、换一个网络，昨天能用的今天可能不能用。

所以流程是：**到新环境先花五分钟验三条链**——网页截图、PDF 下载、视频下载；把结果记进当次任务的备注里。别假设上一份笔记适用。

本仓库的开发机器上（2026-11-06）网页截图链可用、视频平台下载遇到 bot 验证；这是**那台机器在那个时间点**的情况，不是对任何平台的通用结论。换环境要重测。

## 三、网页截图：`snap_news.mjs`

```powershell
node scripts/snap_news.mjs jobs.json [只截的id…]
```

`jobs.json`：

```json
[{"id":"gazette","url":"https://www.info.gov.hk/gia/general/today.htm",
  "find":["行政長官","立法會"],"off":140,"to":"行政長官今日"}]
```

- `find`：要高亮的关键词，**必须真的出现在当前可视区**。滚到页顶经常命中 0——用 `to` 指定正文里的一句话，页面会滚到那句话。
- `off`：标题/定位句离顶部多少像素。
- 输出 `docs/<id>.png`（1600×1000 视口、2 倍像素）和 `docs/news.json`（标题与关键词框坐标，荧光笔用）。

**截图前先看一眼**：脚本会打印命中的数量。命中 0 就说明词不在可视区，或者页面结构跟预期不同——**不要拿命不中的截图去刷黄**。

**繁体站和简体站都能截**，但要注意：同一个词在长短体写法不同（`立法會` / `立法会`），`find` 要照页面实际用的写法。

**被验证码拦住**就换路：用核实过的文字自己排版成"摘录卡"，画面标明"非网页截图"（上游 `article` 的 `mock` 就是这个用途，注意不要仿真实站点的 logo 和版式）。

## 四、PDF 与公报

议会文件、政策文件多为 PDF。做法：

1. 下载 PDF → 渲染成图（`pdftoppm` 或系统预览截图）；
2. 裁到那一段，`article` 的 `img` 用它；
3. 关键句用 `hl` 刷黄（坐标按图片像素算，`cssScale` 处理 2 倍像素）。

**PDF 原页图比网页截图更稳**（不会被反爬改版），但字号通常很小，需要推近才能读。`article` 的 `zoom` 给到 2.0–2.6。

## 五、视频：官方录像

用 `scripts/footage.py`：

```powershell
python scripts/footage.py search "立法會 記者會" -n 8
python scripts/footage.py get <id> --section 00:12:30-00:12:50 -o hearing
python scripts/footage.py sheet hearing.mp4 --step 2
python scripts/footage.py scenes hearing.mp4
```

依赖 `yt-dlp`，它需要保持更新（版本太老会被平台拒绝）。平台的人机验证（"确认你不是机器人"）**在部分网络或账号环境下会持续拦截下载**。遇到时：

- 更新 yt-dlp 到最新；
- 如果平台提供 cookies 方式，用你**自己有权使用**的浏览器会话；
- **不要无限重试**，也不要为了绕过平台规则去用第三方镜像站。

**下载失败就往下走降级路径。** 官方视频路径在很多环境里是通的，但不能假设、也不该写死成"一定能下"。

## 六、降级路径（按优先级）

1. **官方页面真实截图**（首选）
2. **PDF 原页图**
3. **用户提供的片段**（`user-provided` + `local_path`）
4. **摘录卡**：把核实过的原文按自己的版式排出来，画面标明"原文摘录，非网页截图"
5. **自绘时间线/表格**：只演时间顺序和数字，注明数据来源

**降级不是造假，但要标清楚。** 用了摘录卡就不能让观众以为是网页截图；用了自绘图表就要在角标里写来源。

## 七、素材清单：必须交代的

交片时给一份清单，每条写：

- 用了哪家、哪篇、哪天（`editorial.json` 的 `sources`）
- 哪几镜用了它（镜头的 `sourceIds`）
- 哪些是引用/评论，哪些是自制

第三方的画面、照片、logo、音乐**不因代码是 MIT 就获得再分发许可**。

## 八、真实热点，每次重新查

本地操作指南和任何旧笔记里的"事实"都不是今后核验的依据。**涉及"现在""今天""刚刚"的，出片前重新打开来源页面确认一次**；日期、职位、职务会变。
