# 港台本地语言：用词、句式、语音

**先写本地正文，再做字形转换。** 把普通话稿直接转成繁体，读者一眼能看出是"改过来的"。这份讲三条：语音怎么选、地区语言怎么写、哪些地方最容易翻车。

## 一、语音：不许静默回落

| 地区 | 主选（男声） | 备选女声 | 语言代码 |
|---|---|---|---|
| `taiwan` | `zh-TW-YunJheNeural` | `zh-TW-HsiaoChenNeural` / `zh-TW-HsiaoYuNeural` | `zh-TW`（台湾国语） |
| `hongkong` | `zh-HK-WanLungNeural` | `zh-HK-HiuMaanNeural` / `zh-HK-HiuGaaiNeural` | `yue-HK`（粤语） |

写在 `script.json` 里：

```json
{"voice": "zh-HK-WanLungNeural", "rate": "-4%"}
```

**硬规矩**：

- 香港版**必须**用 `zh-HK-*`。用 `zh-TW` 或 `zh-CN` 读粤语字会读成普通话音，那是另一种语言，不是"口音不同"。
- 音色不存在或服务报错时**抛真实错误**，不能悄悄退回 `zh-CN-YunxiNeural` 交片。
- 改 `voice` 或改 `text` 之后**必须重新生成时间线**（`temp_voice.py`），不能复用旧配音的缓存。

**我能验什么、不能验什么**：能验"文本没被跳过、时长合理、音色 ID 正确"；**不能验母语听感**——那要人耳。交付时如实说，不要写"已确认地道"。

## 二、台湾：词汇、句式、黑话

### 词表（左：用这个；右：不要）

| 用台湾说法 | 少用 |
|---|---|
| 影片、短影音、網路、網友、洗版 | 视频、網絡、群眾刷屏 |
| 國語、台灣、台北、台積電 | 普通話 |
| 立委、立法院、國會、質詢、政見、協商、覆議 | 把立委一律叫議員、把質詢寫成詢問 |
| 預算案、財源、期程、縣市、里長、選民 | 落地執行、時程（台湾用「時程」） |
| 捷運、計程車、營養午餐 | 地鐵、出租車、學生餐 |
| 螢幕、程式、資料、專案 | 屏幕、程序、数据、项目 |

### 口语骨架（一次只用一两个，不要每句加）

`欸，各位先想一下` / `坦白講` / `問題來了` / `拜託` / `說真的` / `你把這兩件事放在一起看`

**不要**为了"像台湾腔"每句都加「齁」「啦」「吼」——那是模仿，不是写作。

### 时评可用词（先理解指涉和时间，别乱用）

`卡關、翻車、跳針、帶風向、聲量、洗版、藍白合、綠營、小草、拆招、喊話`

**注意**：`網軍、側翼、喬事情、黑箱` 若是具体指控，**必须有来源，或明写"这是对方的说法"**；不能因为选了某个 stance 就自动安到某个人身上。

## 三、香港：粤语先写，再排字幕

香港版的 `text` 必须是**自然的书面粤语**，不是"繁体普通话"。TTS 也直接读这份粤语文本。

### 常用粤字

`佢、佢哋、嘅、喺、唔、冇、咗、啲、咁、嗰、乜、嚟、嘢、係、畀`

### 句式

`講咗咁耐` / `點解又押後？` / `咁即係點？` / `條數邊個埋？` / `街坊最關心嘅係` / `唔好淨係講口號` / `講到尾，係邊個負責？`

### 地区词

`特首、特區政府、立法會、議員、局方、問責、街坊、屋苑、管理處、劏房、打工仔、埋單、交代、配套、指定袋、垃圾徵費`

### 黑话/讽刺（按题材挑，不要一分钟塞满）

`拖字訣、甩鍋、扯貓尾、兜圈、食花生、離地、講一套做一套`

**不要**把香港写成"全部用同一句粗口"或"全部一个政治立场"。

### 粗口档位

| 档位 | 粤语写法 | 说明 |
|---|---|---|
| `none` | — | 愤慨靠句式和节奏 |
| `mild` | `搞乜鬼呀？` | 一条片最多一两处，每处给无粗口替代 |
| 更重 | 按实际语义单独处理 | **不要把普通话粗口直译进粤语**，会显得生硬且语境不对 |

### 原话保留原字形

引用别人说的话时，**保留原文字形和措辞**（可能是书面语或普通话），只有你自己的说明和转述用当地语气。改原话就是改事实。

## 四、字幕的本地化

- **台湾**：一行 8–15 字；繁体字比简体宽，`subMax` 收到 12。
- **香港**：可以保留读出来的粤字，不强制改成"他們說不會加價"。
- **不要**渲完字幕再全片简转繁——cue 和索引会错位。繁体正文一开始就写好，时间线从它为基准生成。

## 五、最容易翻车的四处

1. **只换字形不换词**：`視頻 → 視頻` 还是大陆词，正确的是 `影片`。
2. **把粤语写成繁体普通话**：`他们说不加价` 用粤语音色读，出来四不像。
3. **数字和专名没处理**：`2026` 要写 `二零二六` 才会念得对（`say` 字段可以单独给读法）。
4. **为了口音堆语气词**：`齁`「啦」堆满，比不写还假。

## 六、自查清单

- [ ] `script.json` 的 `voice` 是 `zh-HK-*`（香港）或 `zh-TW-*`（台湾）
- [ ] 香港的 `text` 里有粤字（唔/嘅/咗/佢…），不是繁体普通话
- [ ] 台湾的 `text` 里没有「视频/網絡/出租車/地鐵」
- [ ] 数字写成中文读法
- [ ] 原话引用没有被"本地化"改写
- [ ] 改了 text 之后重跑过 `temp_voice.py`
