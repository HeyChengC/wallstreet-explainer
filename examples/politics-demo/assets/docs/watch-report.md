# 白皮書逐頁核對（測試材料）

> **這是為示例片合成的虛構報告**，「海嵐觀察」不是真實團體。

## 方法

把白皮書 147 頁逐頁全文檢索，統計關鍵詞出現次數；兩個研究員各自數一遍，對不上的回原文核。

## 結果

| 關鍵詞 | 次數 |
|---|---|
| 過海隧道 | 26 |
| 收費 / 通行費（都在「另行公布」「不涉及調整」這類句子裡） | 4 |
| 具體費率 / 收費起始日 / 測算數字 | 0 |

## 結論（虛構團體的觀點）

白皮書提到了收費，但沒有給任何費率、起始日或測算。方案通過後，收費若以技術調整方式落地，將不再需要議會逐次投票。這是本團體最擔心的一點。
