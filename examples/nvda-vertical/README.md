# 样片：《英伟达拒绝老黄回归》竖屏真人口播（28.7 秒，8 镜）

这是 vpro 精装组件（`kit/vpro.js`）的样片：用户看到第九版说"行"的那一版，2026-11-20。

**样片是质量的底，不是模板。** 下一条片要做到这个水平，但每一镜要有自己的演法：换道具、换词、换哪一镜最重。照着这份镜头表换字，出来的是第二条一模一样的片子。

## 这里有什么

| 文件 | 是什么 |

## 这条片是怎么定下来的

口播是用户给的竖屏视频，原话一字不改。前八版被打回的原因，按出现顺序：

1. 证据全是白卡，平，像 PPT → 换成有厚度、有前后层的东西。
2. 八镜都是同一种"砸下来"，重复 → 八镜八种进场。
3. 只有字和卡，没有会演的东西 → 加道具，演口播里的词（反转、泼冷水、拍板、印钞机）。
4. 漫画气泡、红章、警戒带、荧光绿混在一起，怪 → 全片一套颜色、一种卡。
5. 金字棕边、代码画的道具、到处在晃，廉价 → 颜色取自她的紫灰开衫；道具换真照片抠图和生图；落定后不动。

第 5 条是把参考片（小Lin说）和自己的同类镜头放大并排看才看出来的。所以开工第一步是并排对照，见 `SKILL.md`。

## 没验证过的

- 音效（26 个点，Freesound 真录）没有人听过。
- 进场的连续动作只逐帧看过法槌、水桶、新闻卡三处。
