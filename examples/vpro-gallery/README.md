# vpro 图形组件样张

`film.js` 一镜放一个组件，一共 12 个（提问、柱子、对比、因果链、要点、走势线、图窗、引语、时间线、占比、排行、分段），没有口播。`gallery12.jpg` 是每镜落定的一帧。

想自己跑：`node scripts/new_film.mjs <目录> --vertical`，把这里的 `film.js` 拷过去，图换成自己的，`render.mjs --dir <目录> --sheet`。

里面的数来自英伟达和黄金两条样片；标了"示意"的两镜（走势线、排行）是编来看版式的，不是真数据。照片出处见 `../nvda-vertical/README.md`。
