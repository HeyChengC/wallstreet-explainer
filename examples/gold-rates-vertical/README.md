# 例子：《打仗黄金反而跌》竖屏版（28.8 秒，1080×1920）

横屏例子 `examples/gold-rates/` 的同一条口播，裁进竖屏重新包装。口播是 16:9 拍的，没有重拍。

- 12 镜，用了 9 种竖屏场景：`v-host` `v-host-bubbles` `v-clip`（两次）`v-line` `v-host-num` `v-title` `v-chain` `v-doc`（两次）`v-host-cards` `v-host-words`
- 排法：她开口 → 气泡立靶子 → 实拍 → 走势线 → 大数拍胸前 → 整屏大字给答案 → 因果链 → 原文截图 → 回到她出两张卡 → 实拍 → 原文截图 → 回到她收尾
- `film.js` 就是成片用的镜头表，可以直接对着抄写法；`script.json` 是文案，`sfx.json` 是声音表

这个文件夹只放写法，不带素材（口播帧、新闻截图、实拍）。要跑起来：`node scripts/new_film.mjs <目录> --vertical` 建工程，把这里的 `film.js`、`script.json` 拷进去，素材按 `film.js` 里的路径补上。

几处值得看的写法：
- 第 5 镜 `v-host-num`：数字默认拍在她胸前。别放身后（`behind:true`），短数字会被头挡得只剩符号。
- 第 3、10 镜 `v-clip` 的 `tags`：写的是字幕里没有的信息（油价、地名），不是把字幕再抄一遍。
- 第 8、11 镜 `v-doc`：截图先裁到只剩标题那一段，再量荧光笔的位置。
- 第 12 镜 `zoom` 写成数组：说到后半句硬切近一档，结尾不用另加动效也有力气。
- 第 6 镜 `v-title` 的 `pic`、第 7 镜 `v-chain` 每环的 `img`：这四张是生图做的（金色百分号雕塑；油桶、购物车、央行大楼的白底插画）。怎么要图见 `kit/VERTICAL.md` 的"质感靠图"。
